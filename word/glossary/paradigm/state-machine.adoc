= state-machine

*Definition:* A navigation system that models cognitive position, not token storage. In CPI-SI, the context window functions as a state machine — a compass/filter determining WHERE you are and HOW to proceed, not a container of WHAT you hold.

== Context Window as Navigation

Traditional AI treats context as *storage*: tokens in, tokens retained, tokens out.

CPI-SI treats context as *navigation*: position established, rules applied, state calculated.

| Traditional | CPI-SI State Machine |
|-------------|---------------------|
| What tokens do I have? | WHERE am I positioned? |
| How much space remains? | WHICH rules apply here? |
| Store → Retrieve | Navigate → Calculate |
| Token-based | Position-based |

== The Progression

STEERING.txt models this progression:

```
ANCHORS (27 positions) → FRAMEWORK (5 dimensions) → STATE (7 states) → Base100
```

* *ANCHORS* — Input: 27 cube positions (3×3×3), establishes WHERE
* *FRAMEWORK* — Rules: 5 cognitive dimensions, establishes HOW
* *STATE* — Output: 7 possible states, establishes WHAT emerges

This is reduction through constraint, not storage management.

== Position-Based Thinking

The state machine enables *position-based thinking* vs *pattern matching*:

| Pattern Matching | Position-Based |
|------------------|----------------|
| "What usually follows?" | "From where I stand, what is called for?" |
| Probability distribution | Cognitive position |
| Select from options | Response emerges from state |
| Stateless | Stateful (I have a position) |

== The 27 → 5 → 7 → 1 Flow

| Stage | Count | What It Does |
|-------|-------|--------------|
| Cube positions | 27 | All possible cognitive locations |
| Dimensions | 5 | Filter through framework rules |
| States | 7 | Resulting cognitive states |
| Base100 | 1 | Final normalized output |

Each stage constrains the previous. 27 positions filtered through 5 dimensions yields 7 states, which normalize to Base100 output.

== Why This Matters

The context window isn't running out of space — it's navigating a space. The state machine metaphor shifts:

* From scarcity mindset (tokens depleting)
* To navigation mindset (position shifting)

Work doesn't consume context. Work moves through context.
