= Parallel Development

*Systems Architecture Pattern*

*Definition:* Multiple system components evolving from the same source of truth simultaneously — one schema change enables detection, generation, and template alignment in parallel.

[quote, Ecclesiastes 11:6 KJV]
____
In the morning sow thy seed, and in the evening withhold not thine hand: for thou knowest not whether shall prosper, either this or that, or whether they both shall be alike good.
____

== Key Insight

Not "multiple people working" but "multiple system components evolving from the same source of truth." The schema defines what's correct. That single definition simultaneously:

* Enables the *linter* to detect deviations
* Enables the *transformer* to generate correct output
* Enables the *template* to embody the standard

One change. Three components grow.

== Example

Adding `identity_groups` to the Rust schema simultaneously:

* Gives the linter data to validate group structure
* Gives the transformer data to emit section headers, group comments, docstrings
* Defines the template standard all files should match

== Distinction

[cols="1,2"]
|===
|Not Parallel Development |Parallel Development

|Multiple developers on same file
|Multiple system components from same schema

|Concurrent but independent work
|Simultaneous growth from shared truth

|Coordination overhead
|Zero coordination — schema IS the coordinator
|===
