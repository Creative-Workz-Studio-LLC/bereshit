= section

*Definition:* The atomic unit of editing granularity WITHIN a block. Maps to T at the block scale - the smallest meaningful piece that cannot be subdivided without losing coherence.

[quote, Nehemiah 3:28 KJV]
____
From above the horse gate repaired the priests, every one over against his house.
____
link:../../scripture/KJV/Nehemiah/Chapter_3/Verse_28.txt[Read verse ^]

== Fractal T-B-Q Pattern

The ternary pattern applies at EACH scale:

[cols="1,1,1,1"]
|===
|Scale |T (atomic) |B (transitional) |Q (complete)

|*File*
|Block
|between blocks
|Whole file

|*Block*
|Section
|Chunk
|Whole block

|*Section*
|Line/element
|related lines
|Whole section
|===

== What It Is

* Smallest addressable unit within a block
* Surgical precision - edit ONE coherent piece
* Context preserved around the edit
* Like a single definition, single function signature, single table

== When To Use Section-Level Editing

* Fine-grained corrections within a block
* Updating a single value or definition
* Surgical fixes that shouldn't disturb surrounding content
* When chunk-level would change too much
