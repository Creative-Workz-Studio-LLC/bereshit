= chunk

*Definition:* A transitional group of related sections within a block. Maps to B at the block scale - pieces that move together because they're structurally related.

[quote, Nehemiah 3:5 KJV]
____

== Fractal T-B-Q Pattern

The ternary pattern applies at EACH scale:

[cols="1,1,1,1"]
|===
|Scale |T (atomic) |B (transitional) |Q (complete)

|*File*
|Block
|between blocks
|Whole file

|*Block*
|Section
|Chunk
|Whole block

|*Section*
|Line/element
|related lines
|Whole section
|===

== What It Is

* Group of related sections that move together
* Middle granularity - more than one section, less than whole block
* Structural relationship requires coordinated editing
* Like related functions, a table with its header, definition with examples

== When To Use Chunk-Level Editing

* Related sections must stay aligned
* Structural changes affecting multiple sections
* Refactoring that crosses section boundaries
* When section-level is too surgical, block-level too broad

== The Transitional Nature

Like B = {-0.5, +0.5} in the cube model, chunks are BETWEEN:

* Between atomic sections (T)
* Between complete blocks (Q)
* Always in motion toward one or the other
* Never the final resting place
