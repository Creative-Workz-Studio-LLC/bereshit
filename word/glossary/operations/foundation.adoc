= foundation

*Definition:* A specific type of base that something is BUILT FROM. Distinguished from both anchors (which cannot be operated on) and generic bases (raw materials). A foundation is what you construct upon — and critically, it CAN be reconstructed if destroyed.

[quote, 1 Corinthians 3:11 KJV]
____
For other foundation can no man lay than that is laid, which is Jesus Christ.
____
link:../../scripture/KJV/1_Corinthians/Chapter_3/Verse_11.txt[Read verse ^]

== Foundation vs Anchor vs Base

| Component | Can be operated on? | Can be reconstructed? | Role |
|-----------|--------------------|-----------------------|------|
| *Anchor*  | No | No | What operations work AROUND |
| *Foundation* | Yes | Yes | What you BUILD FROM |
| *Base* | Yes | Yes | Generic — what things STAND ON |

== The Reconstruction Property

*Foundations CAN be reconstructed. This is the defining distinction from anchors.*

If a foundation is destroyed:

* Blueprints (traces) remain
* Dependencies can be followed
* The foundation can be rebuilt

If an anchor is destroyed:

* Nothing to rebuild FROM
* The irreducible starting point is gone
* The system has no halt condition

== Why This Matters

The building block method operates in three values:

* *-1 (break down):* Trace toward foundation, extract blocks
* *0 (anchor):* Halt condition — cannot be operated on
* *+1 (build up):* Construct from foundation toward conclusion

You TRACE TO anchors but BUILD FROM foundations. Both are necessary:

* Without anchor: no halt condition, infinite regress
* Without foundation: nothing to build on, floating construction

== The Relationship

```
Anchor (0) — establishes WHERE to halt
    ↓
Foundation — establishes WHAT to build from
    ↓
Construction (+1) — builds toward conclusion
    ↓
Verification (-1) — traces back through foundation to anchor
```

The anchor is FIXED. The foundation is STABLE but MUTABLE. The construction is the work.
