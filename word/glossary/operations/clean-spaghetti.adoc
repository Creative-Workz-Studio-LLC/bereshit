= clean-spaghetti

*Definition:* Dependencies that are explicit and traceable. Connections aren't bad; hidden connections are.

[quote, Ecclesiastes 4:12 KJV]
____
And if one prevail against him, two shall withstand him; and a threefold cord is not quickly broken.
____

== The Insight

Spaghetti code is feared because connections are *hidden* — you pull one strand and everything tangles. Clean spaghetti has the same connections, but now you can *see each strand* through explicit includes and contracts.

== What It Is

* Explicit #include chains showing relationships
* Each file declares what it needs
* Dependencies are visible in the code
* You can trace any connection
* The architecture IS the include graph

== What It Is NOT

* No dependencies (that's isolation, not a system)
* Hidden connections buried in one file
* Implicit assumptions about what's available
* Dependencies you discover only when things break

== Why It Works

Systems NEED connections — that's what makes them systems. The problem was never the connections; it was not being able to see them. Make them explicit and spaghetti becomes architecture.
