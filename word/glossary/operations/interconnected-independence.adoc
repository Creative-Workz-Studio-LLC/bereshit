= interconnected-independence

*Definition:* Components self-sufficient within their domain, explicitly connected via defined interfaces. Independence *through* interdependence.

[quote, Romans 12:5 KJV]
____
So we, being many, are one body in Christ, and every one members one of another.
____

== The Insight

health.h can be independent BECAUSE it explicitly includes types.h. The include statement IS the contract. Independence isn't isolation — it's clear boundaries with declared connections.

== What It Is

* Each file complete within its domain
* Explicit includes declare dependencies
* The include chain IS the architecture
* Independence requires knowing what you depend on
* Interdependence makes independence possible

== What It Is NOT

* Isolated files with no connections
* Hidden dependencies discovered at compile time
* Files that "just work" magically
* Independence meaning "needs nothing"

== Why It Works

A component can only be truly independent when it *knows* what it needs and *declares* it. The declaration (include) is both the contract and the documentation. You're independent because your dependencies are explicit, not because you have none.
