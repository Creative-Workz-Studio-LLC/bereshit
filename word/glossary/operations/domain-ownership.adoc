= domain-ownership

*Definition:* Each domain file owns its types. The root provides foundation, children provide specialization.

[quote, 1 Chronicles 9:26 KJV]
____
For these Levites, the four chief porters, were in their set office, and were over the chambers and treasuries of the house of God.
____

== The Insight

health.h doesn't just USE health types — it OWNS them. The root (types.h) provides the foundation everyone needs. Each child provides what only it needs. Ownership is clear.

== What It Is

* Each domain file defines its own types
* Root provides universal foundation only
* Children are complete within their domain
* Ownership = where the type is defined
* Include chain shows who provides what

== What It Is NOT

* Everything in the root "just in case"
* Children only using, never defining
* Unclear ownership across files
* Types floating without a home

== Why It Works

When ownership is clear, you know where to look. Need health types? health.h owns them. Need foundation types? types.h owns those. The question "where does this belong?" has an answer.
