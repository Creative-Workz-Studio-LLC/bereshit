[[scale-normalization]]
== Algorithm Family 1: Scale Normalization

Map raw values to the 5 hard anchor points, producing consistent "just weights".

[%collapsible%open]
.Algorithm 1.1: StoredToTrue — Foundation Conversion
====
*Converts storage value to true ternary score*

This is the FOUNDATION conversion. All other algorithms build on this.

[source,pseudocode]
----
ALGORITHM StoredToTrue(stored: uint8) → int8
    // stored: 0-255 (storage foundation)
    // returns: -100 to +100 (true ternary score)

    // Linear mapping: 0 → -100, 128 → 0, 255 → +100
    // Formula: (stored - 128) * 100 / 127

    numerator ← (stored - 128) × 100
    true_value ← numerator / 127

    RETURN true_value
END ALGORITHM
----

*Key Properties:*

* Anchor: 128 → 0 (the "even balance")
* Symmetric: 0 → -100, 255 → +100
* Deterministic: same input always same output
====

[%collapsible%open]
.Algorithm 1.2: TrueToStored — Inverse Conversion
====
*Converts true ternary score back to storage value*

[source,pseudocode]
----
ALGORITHM TrueToStored(true_value: int8) → uint8
    // true_value: -100 to +100 (true ternary score)
    // returns: 0-255 (storage value)

    // Inverse mapping: -100 → 0, 0 → 128, +100 → 255
    // Formula: (true_value * 127 / 100) + 128

    scaled ← (true_value × 127) / 100
    stored ← scaled + 128

    RETURN stored
END ALGORITHM
----

*Key Properties:*

* Inverse of StoredToTrue
* Round-trip property: TrueToStored(StoredToTrue(x)) ≈ x
* Small rounding errors due to integer division
====

[%collapsible]
.Algorithm 1.3: Normalize (Multi-Base) — Generalized Normalization
====
*Rounds true score to nearest hard point for given base*

This is the GENERALIZED normalization supporting all bases (1, 5, 10, 20, 25, 50).

[source,pseudocode]
----
ALGORITHM Normalize(true_value: int8, base: uint8) → int8
    // true_value: -100 to +100
    // base: step size (1, 5, 10, 20, 25, 50)
    // returns: normalized to nearest key point

    IF base = 1 THEN
        RETURN true_value  // Base1 = full precision, no rounding
    END IF

    // Formula: round(true_value / base) * base
    quotient ← true_value / base
    rounded ← ROUND(quotient)
    normalized ← rounded × base

    // Clamp to valid range
    IF normalized < -100 THEN
        normalized ← -100
    END IF
    IF normalized > 100 THEN
        normalized ← 100
    END IF

    RETURN normalized
END ALGORITHM
----
====

[%collapsible%open]
.Algorithm 1.4: NormalizeBase50 — The 5 Hard Points
====
*The PRIMARY normalization - produces the 5 hard anchor points*

This is the DEFAULT for statusline display and quick-glance health.

[source,pseudocode]
----
ALGORITHM NormalizeBase50(true_value: int8) → int8
    // Specialized version for base50 (5 hard points)
    // Output: one of [-100, -50, 0, +50, +100]

    // Boundary-based approach (faster than division)
    IF true_value ≤ -75 THEN
        RETURN -100
    ELSE IF true_value ≤ -25 THEN
        RETURN -50
    ELSE IF true_value ≤ 25 THEN
        RETURN 0
    ELSE IF true_value ≤ 75 THEN
        RETURN +50
    ELSE
        RETURN +100
    END IF
END ALGORITHM
----

*The 5 Hard Points:*

[cols="^1,2,2", options="header"]
|===
| Point | True Range | Meaning
| -100 | -100 to -75 | Fully wanting
| -50 | -74 to -25 | Significantly wanting
| 0 | -24 to +24 | Even balance (anchor)
| +50 | +25 to +74 | Significantly whole
| +100 | +75 to +100 | Full integrity
|===

STRUCTURE TemporalState

ALGORITHM CreateBaseState(dimension: int8) → TemporalState
    // Create simple temporal state
    state.lens ← dimension
    state.target ← dimension  // Same as lens for base states
    state.is_compound ← false
    RETURN state

ALGORITHM CreateCompoundState(lens: int8, target: int8) → TemporalState
    // Create compound temporal state
    IF lens = target THEN
        RETURN CreateBaseState(lens)  // Self-reference = base state
    END IF

    state.lens ← lens
    state.target ← target
    state.is_compound ← true
    RETURN state

ALGORITHM HealthTrajectory(

    ELSE IF delta > +25 THEN

        RETURN 0   // Stable
    END IF
END ALGORITHM

[[calculus-operations]]
== Algorithm Family 4: Calculus Operations

Detect and measure change over time — the discrete analog of calculus.

[NOTE]
====
*Biblical grounding:*

* *Ecclesiastes 3:1* — "To every thing there is a season" — Time awareness, when to act
* *Genesis 1:14* — "for signs, and for seasons, and for days, and years" — Discrete time intervals
* *Proverbs 22:28* — "Remove not the ancient landmark" — Boundaries (גְּבוּל gevul) as thresholds
====

These operations enable health systems to know *when* precision matters:

[cols="2,4", options="header"]
|===
| Operation | Purpose
| *Difference* | How much changed? (Δ)
| *Rate* | How fast is it changing? (derivative approximation)
| *Accumulation* | Total change over time? (integral approximation)
| *Threshold* | Did we cross a boundary? (level transition)
| *Trend* | Which direction overall? (returns trit_t)
| *Critical* | Does rate exceed alarm threshold?
|===

[%collapsible%open]
.Algorithm 4.1: TritDifference — Change Detection
====
*Calculates the delta between two health values*

This is the foundation of change detection — the discrete analog of differentiation.

[source,pseudocode]
----
ALGORITHM TritDifference(current: int8, previous: int8) → int8
    // current: current true ternary score (-100 to +100)
    // previous: previous true ternary score (-100 to +100)
    // returns: difference (can exceed -100 to +100 range)

    delta ← current - previous

    RETURN delta
END ALGORITHM

ALGORITHM TritDifferenceNormalized(current: int8, previous: int8) → int8
    // Returns difference normalized to -100 to +100 range
    // Useful when comparing differences across scales

    delta ← current - previous

    // Clamp to valid range
    IF delta < -100 THEN
        delta ← -100
    END IF
    IF delta > 100 THEN
        delta ← 100
    END IF

    RETURN delta
END ALGORITHM
----

*Key Properties:*

* Positive delta = improving (toward integrity)
* Negative delta = declining (toward wanting)
* Zero delta = stable
====

[%collapsible%open]
.Algorithm 4.2: TritRate — Rate of Change
====
*Calculates rate of change over time — discrete derivative approximation*

[source,pseudocode]
----
ALGORITHM TritRate(
    current: int8,
    previous: int8,
    time_delta: uint32    // time units between readings
) → int8
    // Returns rate of change per time unit
    // Approximates the derivative: dHealth/dTime

    IF time_delta = 0 THEN
        RETURN 0  // Avoid division by zero
    END IF

    delta ← current - previous
    rate ← delta / time_delta

    // Clamp to valid range
    IF rate < -100 THEN
        rate ← -100
    END IF
    IF rate > 100 THEN
        rate ← 100
    END IF

    RETURN rate
END ALGORITHM
----

*Time units are configurable:* seconds, minutes, hours, days — depending on context.

*Example:*
[source]
----
current = +50, previous = +25, time_delta = 5 days
rate = (50 - 25) / 5 = +5 per day (improving)

current = -25, previous = +50, time_delta = 3 days
rate = (-25 - 50) / 3 = -25 per day (declining rapidly)
----
====

[%collapsible%open]
.Algorithm 4.3: TritAccumulate — Running Sum
====
*Calculates accumulated change over a time window — discrete integral approximation*

[source,pseudocode]
----
ALGORITHM TritAccumulate(
    history: int8[],      // array of true ternary scores
    window_size: uint32   // number of readings to consider
) → int8
    // Returns accumulated change over the window
    // Approximates the integral: ∫Health dt

    IF LENGTH(history) < 2 THEN
        RETURN 0  // Not enough data
    END IF

    // Use last 'window_size' entries (or all if fewer)
    start_index ← MAX(0, LENGTH(history) - window_size)
    total_change ← 0

    FOR i ← start_index + 1 TO LENGTH(history) - 1
        delta ← history[i] - history[i-1]
        total_change ← total_change + delta
    END FOR

    // This equals: history[last] - history[start]
    // But computing incrementally allows weighted accumulation later

    RETURN total_change
END ALGORITHM

ALGORITHM TritAccumulateWeighted(
    history: TemporalHealth[],
    window_size: uint32
) → int8
    // Time-weighted accumulation — recent changes matter more

    start_index ← MAX(0, LENGTH(history) - window_size)
    weighted_sum ← 0
    total_weight ← 0

    FOR i ← start_index + 1 TO LENGTH(history) - 1
        delta ← history[i].true_value - history[i-1].true_value
        weight ← i - start_index  // More recent = higher weight

        weighted_sum ← weighted_sum + (delta × weight)
        total_weight ← total_weight + weight
    END FOR

    IF total_weight = 0 THEN
        RETURN 0
    END IF

    RETURN weighted_sum / total_weight
END ALGORITHM
----

ALGORITHM ThresholdCrossed(
    current: int8,
    previous: int8
) → ThresholdEvent
    // Returns information about level boundary crossings

    STRUCTURE ThresholdEvent
        crossed: bool           // Did we cross a boundary?
        direction: int8         // -1 = worsened, +1 = improved
        from_level: string      // Previous level name
        to_level: string        // Current level name
        significance: int8      // Number of levels crossed (1-6)
    END STRUCTURE

    event.from_level ← TrueToLevel(previous)
    event.to_level ← TrueToLevel(current)
    event.crossed ← (event.from_level ≠ event.to_level)

    IF NOT event.crossed THEN
        event.direction ← 0
        event.significance ← 0
        RETURN event
    END IF

    // Calculate direction and significance
    level_order ← ["broken", "wanting", "lacking", "even",
                   "sound", "whole", "perfect"]

    from_index ← INDEX_OF(level_order, event.from_level)
    to_index ← INDEX_OF(level_order, event.to_level)

    event.significance ← ABS(to_index - from_index)

    IF to_index > from_index THEN
        event.direction ← +1  // Improved
    ELSE
        event.direction ← -1  // Worsened
    END IF

    RETURN event
END ALGORITHM

ALGORITHM TrendDirection(
    history: int8[],      // array of true ternary scores
    threshold: int8       // minimum delta to be considered non-stable
) → int8
    // Returns: -1 (declining), 0 (stable), +1 (improving)
    // This IS the building block method applied to health over time

    IF LENGTH(history) < 2 THEN
        RETURN 0  // Not enough data — anchor at stable
    END IF

    first ← history[0]
    last ← history[LENGTH(history) - 1]
    delta ← last - first

    // Apply ternary threshold (default 25 = one hard point)
    IF threshold = 0 THEN
        threshold ← 25
    END IF

    IF delta < -threshold THEN
        RETURN -1  // Declining (break_down direction)
    ELSE IF delta > threshold THEN
        RETURN +1  // Improving (build_up direction)
    ELSE
        RETURN 0   // Stable (anchor)
    END IF
END ALGORITHM

ALGORITHM CriticalRate(
    rate: int8,              // from TritRate()
    critical_threshold: int8 // rate at which to alert (negative)

    // Checks if rate of change indicates critical situation

    STRUCTURE CriticalAlert
        is_critical: bool     // Should we alert?
        severity: string      // "warning", "critical", "emergency"
        rate: int8            // The rate that triggered
        message: string       // Human-readable description
    END STRUCTURE

    alert.is_critical ← false

    // Default threshold: -10 per time unit
    IF critical_threshold = 0 THEN
        critical_threshold ← -10
    END IF

    // Only negative rates can be critical
    IF rate >= 0 THEN
        alert.severity ← "none"
        alert.message ← "Health stable or improving"
        RETURN alert
    END IF

    // Check severity levels
    IF rate <= critical_threshold × 3 THEN
        alert.is_critical ← true
        alert.severity ← "emergency"
        alert.message ← "Rapid decline — immediate attention required"

    ELSE IF rate <= critical_threshold × 2 THEN
        alert.is_critical ← true
        alert.severity ← "critical"
        alert.message ← "Significant decline — attention needed"

    ELSE IF rate <= critical_threshold THEN
        alert.is_critical ← true
        alert.severity ← "warning"
        alert.message ← "Decline detected — monitor closely"

    ELSE
        alert.severity ← "none"
        alert.message ← "Minor decline within tolerance"
    END IF

    RETURN alert
END ALGORITHM
