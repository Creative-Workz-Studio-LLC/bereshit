== The 3 Commands

=== Ternary Decision Model

[cols="1,1,3"]
|===
|Command |Value |Description

|HALT
|-1
|Terminal state. Accumulates only, no forward flow.

|AWAIT
|0
|Pause state. Receives and processes, waits for signal.

|PROCEED
|+1
|Flow state. Receives, processes, forwards automatically.
|===

=== Command Flow

[source]
----
    Input → [Position] → Output
              │
              ├── HALT:    Accumulate, stop
              ├── AWAIT:   Process, wait
              └── PROCEED: Process, forward
----
