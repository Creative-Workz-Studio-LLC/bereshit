[[types]]

[[configfile]]
=== ConfigFile

****
[.lead]
*Represents a single loaded configuration file:*

[source,go]
----
type ConfigFile struct {
    Name string         // filename without extension (e.g., "primitives")
    Path string         // full path to the file
    Data map[string]any // parsed TOML data
    Keys []string       // top-level keys in the file
}
----

.ConfigFile Fields
[cols="2,4",options="header,autowidth",frame="topbot"]
|===
| Field | Description

| `Name`
| The file's base name without `.toml` extension

| `Path`
| Absolute path to the source file

| `Data`
| Parsed TOML content as nested maps

| `Keys`
| Sorted list of top-level keys for summary reporting
|===
****

'''

[[loadresult]]
=== LoadResult

****
[.lead]
*Returned by `LoadAll()` and category loaders — aggregates loading results:*

[source,go]
----
type LoadResult struct {
    Valid   bool                    // true if all files loaded without error
    Configs map[string][]*ConfigFile // loaded files grouped by category
    Errors  []error                 // any errors encountered
    Summary map[string][]string     // category → list of names/keys
}
----

.LoadResult Fields
[cols="2,4",options="header,autowidth",frame="topbot"]
|===
| Field | Description

| `Valid`
| `true` only if zero errors occurred

| `Configs`
| Map of category name → slice of loaded ConfigFile pointers

| `Errors`
| Slice of all errors encountered (continues loading on error)

| `Summary`
| Human-readable summary: category → list of loaded names/keys
|===
****

'''

[[discoveryresult]]
=== DiscoveryResult

****
[.lead]
*Returned by `DiscoverAndCompare()` — tripwire comparison result:*

[source,go]
----
type DiscoveryResult struct {
    Manifest   []string // files declared in index.toml
    Discovered []string // files found on disk
    Missing    []string // ERROR: in manifest but not on disk
    Unexpected []string // WARNING: on disk but not in manifest
    Valid      bool     // true if no missing files
}
----

.DiscoveryResult Fields
[cols="2,4",options="header,autowidth",frame="topbot"]
|===
| Field | Description

| `Manifest`
| Files declared in `index.toml` (single source of truth)

| `Discovered`
| Files actually found on disk via filesystem scan

| `Missing`
| icon:exclamation-triangle[] *Tripwire:* Declared but not on disk

| `Unexpected`
| icon:info-circle[] *Warning:* On disk but not declared

| `Valid`
| `true` only if `len(Missing) == 0`
|===

[horizontal]
icon:shield[] *Purpose*:: The tripwire pattern — detects drift between manifest (what _should_ exist) and disk (what _does_ exist).
****

'''

[[dependencynode]]
=== DependencyNode

****
[.lead]
*Used by dependency graph validation — represents a spec in the DAG:*

[source,go]
----
type DependencyNode struct {
    Spec      string   // "system/file.toml" format
    DependsOn []string // dependencies in same format
    Loaded    bool     // tracking for load order validation
}
----

.DependencyNode Fields
[cols="2,4",options="header,autowidth",frame="topbot"]
|===
| Field | Description

| `Spec`
| Spec identifier in `"system/file.toml"` format

| `DependsOn`
| List of specs this node depends on (edges in DAG)

| `Loaded`
| Tracks whether spec has been loaded (for order validation)
|===

[horizontal]
icon:sitemap[] *Purpose*:: Enables `ValidateDependencyGraph()` to detect cycles and missing references.
****

'''

[[indexmanifest]]
=== IndexManifest

****
[.lead]
*Loaded from `index.toml` — the single source of truth for system configuration:*

[source,go]
----
type IndexManifest struct {
    Systems []SystemEntry `toml:"systems"` // 9 systems in dependency order
}

type SystemEntry struct {
    Name        string     `toml:"name"`        // e.g., "math", "types"
    Path        string     `toml:"path"`        // relative path
    Order       int        `toml:"order"`       // 0 = anchor
    Description string     `toml:"description"` // purpose
    Specs       []SpecDef  `toml:"specs"`       // files in system
}
----

[horizontal]
icon:book[] *Location*:: `{core-rel}index.toml` — manifest of all {system-count} systems
icon:sort-amount-asc[] *Order*:: 0 = foundation anchor (math), 8 = highest dependency (filesystem)
****
