# STATE tracks WHAT IS - position and movement through the system.
# 7 sections (calculus aspects), each with temporal/dimensional organization.
#
# PROGRESSION: ANCHORS (9) + FRAMEWORK (4) + STATE (14) = 27 → Base100
#   9 = ANCHORS positions (T × T = 9 temporal modes)
#   4 = FRAMEWORK positions (B × B = 4 navigation rules: B.1-B.4)
#   14 = STATE positions ((T × B) + (B × B × k) = 6 + 8 = 14)
#   Base100 = normalized score (-100 to +100) → action
#
# 7 STATES (3 positions + 4 transitions from 2 changes):
#   POSITIONS (where you CAN BE):
#     1. AT -1     | -100 | blocked/denied     | full break down
#     2. AT 0      |    0 | anchor/halt        | decision point
#     3. AT +1     | +100 | complete/granted   | full build up
#   TRANSITIONS (movement between positions):
#     4. -1 → 0    |  -50 | trace toward anchor| approaching halt
#     5. 0 → +1    |  +50 | build from anchor  | departing halt
#     6. +1 → 0    |  +50 | trace back         | verify to anchor
#     7. 0 → -1    |  -50 | break from anchor  | deeper analysis
#
# 2 CHANGES (complete movements through anchor):
#   -1 → +1 = BUILD (trace to anchor, build to completion)
#   +1 → -1 = TRACE (build back to anchor, break to source)
#
# 5 HARDPOINTS (reference markers from FRAMEWORK):
#   -1.0 | -0.5 | 0 | +0.5 | +1.0
#   These divide the 7 states into measurable positions
#
# INTERNAL ORGANIZATION (each section has):
#   Temporal: PAST (-1), PRESENT (0), FUTURE (+1)
#   Dimensional: MATTER (-1), TIME (0), SPACE (+1)
#   = 7 × 3 × 3 = 63 discrete positions + continuous ranges = pseudo-continuous machine
#
# EQUATIONS:
#
#   POSITION (where):
#     COORD = (MATTER, TIME, SPACE)              [-1.0 to +1.0 each axis]
#     STATE = floor(COORD × 7) + 4               [maps to state 1-7]
#     Base100 = COORD × 100                      [-100 to +100]
#
#   CALCULUS (movement):
#     Δ = target - current                       [delta/distance]
#     v = dΔ/dt = Δ / cycles                     [velocity/rate]
#     a = dv/dt = (v₁ - v₀) / cycles             [acceleration]
#     ∫ = Σ(completed)                           [integral/accumulated]
#
#   TRUE SCORE (balanced assessment):
#     positive = correct / total                  [+0 to +1]
#     negative = wrong / total                    [−1 to −0]
#     true = positive + negative                  [−1 to +1]
#     normalized = true × 100                     [Base100]
#
#   CROSS-MAPPING (multi-dimensional position):
#     ANCHOR_pos = (temporal, inner, depth)       [1-27]
#     FRAMEWORK_pos = (B.1|B.2|B.3|B.4)   [1-4]
#     STATE_state = (position or transition)      [1-7]
#     FULL_COORD = (ANCHOR, FRAMEWORK, STATE)     [address]
#
#   OPERATIONS AT STATES:
#     HALT   = v → 0 (stop at state)              [at 0]
#     LOCK   = state → = (make immutable)         [fix to -1]
#     SHIFT  = sign(v) flip (change direction)    [at any state]
#     UPDATE = recalculate(COORD, Δ, v, Base100)  [continuous]
#
# NUMBER ↔ WORD MAPPING:
#   +0.75 to +1.0 (+75 to +100) = established, granted, complete
#   +0.5 to +0.75 (+50 to +75)  = strong progress, building well
#   0 to +0.5 (0 to +50)        = building, partial
#   -0.5 to 0 (-50 to 0)        = uncertain, unstable
#   -1.0 to -0.5 (-100 to -50)  = blocked, denied
#
