This is a DEVLOG DOCUMENT SCHEMA — not a fill-in-the-blank template.
It defines what devlog documents CONTAIN and how they're structured.

─────────────────────────────────────────────────────────────────
DEVLOG DOCUMENT STRUCTURE
─────────────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────────────────┐
│ METADATA   │ Devlog identity — session, phase, focus            │
├─────────────────────────────────────────────────────────────────┤
│ HEADER     │ The hook — session focus front and center          │
├─────────────────────────────────────────────────────────────────┤
│ CONTEXT    │ Where we are — overview, scope, summary            │
├─────────────────────────────────────────────────────────────────┤
│ CONTENT    │ The session — Progress → Insights →                │
│            │   Decisions → Next Steps                           │
├─────────────────────────────────────────────────────────────────┤
│ FOOTER     │ Grounding — biblical foundation, references        │
└─────────────────────────────────────────────────────────────────┘

─────────────────────────────────────────────────────────────────
DEVLOG CONTENT FLOW (T.1-T.4)
─────────────────────────────────────────────────────────────────

T.1 PROGRESS — What was accomplished?
    The work record for this session.
    Structure: Summary → Files Created/Modified → Milestones

T.2 INSIGHTS — What was learned?
    Wisdom gained during this session.
    Structure: Discoveries → Patterns → Lessons

T.3 DECISIONS — What choices were made?
    Reasoning record for future reference.
    Structure: Decision → Options → Rationale

T.4 NEXT STEPS — Where do we go?
    Direction forward from this session.
    Structure: Immediate → Near-term → Building Toward

─────────────────────────────────────────────────────────────────
DEVLOG LIFECYCLE
─────────────────────────────────────────────────────────────────

Status progression (update M.2):
  Active (session in progress) → Complete (session done) →
  Superseded (replaced by later devlog)

Version: a-XX.XX during session, b-XX.XX when complete

─────────────────────────────────────────────────────────────────
USING THIS SCHEMA
─────────────────────────────────────────────────────────────────

1. cp asciidoc-devlog.adoc destination.adoc
2. Update pragma: template → document, update meta.key
3. Fill METADATA — especially :session-date:, :session-focus:, :phase:
4. Update HEADER — session focus becomes the lead
5. Write CONTEXT — where we are in the phase
6. Build CONTENT — Progress as work happens, Insights as they emerge
7. Record Decisions and Next Steps at session end
8. Ground in FOOTER — connect to Kingdom purpose

The schema guides you through session recording.
Update sections as session progresses (Active → Complete).
