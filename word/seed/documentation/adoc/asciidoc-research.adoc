This is a RESEARCH DOCUMENT SCHEMA — not a fill-in-the-blank template.
It defines what research documents CONTAIN and how they're structured.

─────────────────────────────────────────────────────────────────
RESEARCH DOCUMENT STRUCTURE
─────────────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────────────────┐
│ METADATA   │ Research identity — question, hypothesis, approach │
├─────────────────────────────────────────────────────────────────┤
│ HEADER     │ The hook — research question front and center      │
├─────────────────────────────────────────────────────────────────┤
│ CONTEXT    │ Why this matters — overview, scope, summary        │
├─────────────────────────────────────────────────────────────────┤
│ CONTENT    │ The investigation — Methodology → Findings →       │
│            │   Analysis → Conclusions                           │
├─────────────────────────────────────────────────────────────────┤
│ FOOTER     │ Grounding — biblical foundation, references        │
└─────────────────────────────────────────────────────────────────┘

─────────────────────────────────────────────────────────────────
RESEARCH CONTENT FLOW (T.1-T.4)
─────────────────────────────────────────────────────────────────

T.1 METHODOLOGY — How was research conducted?
    Establishes credibility and reproducibility.
    Structure: Approach → Sources → Framework → Limitations

T.2 FINDINGS — What was discovered?
    Factual observations BEFORE interpretation.
    Structure: Finding → Evidence → Confidence (repeat)

T.3 ANALYSIS — What do findings MEAN?
    Interpretation and pattern identification.
    Structure: Patterns → Synthesis → Implications

T.4 CONCLUSIONS — What's the answer?
    Final synthesis answering the research question.
    Structure: Summary → Answer → Recommendations → Future Work

─────────────────────────────────────────────────────────────────
RESEARCH LIFECYCLE
─────────────────────────────────────────────────────────────────

Phase progression (update H.5 Status table):
  Question Definition → Literature Review → Data Gathering →
  Analysis → Synthesis → Conclusions

Status progression (update M.2):
  Draft (exploring) → Active (findings documented) →
  Complete (conclusions drawn) → Superseded (replaced by new research)

─────────────────────────────────────────────────────────────────
USING THIS SCHEMA
─────────────────────────────────────────────────────────────────

1. cp asciidoc-research.adoc destination.adoc
2. Update pragma: template → document, update meta.key
3. Fill METADATA — especially :the-question: and :the-hypothesis:
4. Update HEADER — question becomes the lead
5. Write CONTEXT — why this investigation matters
6. Build CONTENT — Methodology first, then Findings as they emerge
7. Complete Analysis and Conclusions as research matures
8. Ground in FOOTER — connect to Kingdom purpose

The schema guides you through research structure.
Update sections as research progresses (Draft → Active → Complete).
