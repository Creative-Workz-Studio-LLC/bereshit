[[definition]]
== AsciiDoc Elements

[.lead]
AsciiDoc organizes content into three fundamental element types: *block*, *inline*, and *structural*. Understanding these categories is the foundation for creating well-structured documents.

[cols="2,3,2",options="header"]
|===
| Element Type | Description | Examples

| *Block*
| Self-contained content units that stand alone, separated by blank lines
| Paragraphs, tables, code blocks, admonitions, collapsibles

| *Inline*
| Formatting applied within text flow, no blank line separation
| Bold, italic, links, footnotes, keyboard shortcuts

| *Structural*
| Document organization elements that define hierarchy and metadata
| Sections, attributes, anchors, includes
|===

[%collapsible%open]
.Block Elements: The Building Blocks
====
Block elements are the primary containers for content. Each block type serves a specific purpose:

[cols="2,3,2",options="header"]
|===
| Block | Purpose | Syntax Marker

| *Paragraph*
| Default text container
| (none - just text)

| *Table*
| Structured data in rows/columns
| `\|===`

| *Source/Code*
| Syntax-highlighted code
| `[source,lang]` + `----`

| *Admonition*
| Callout boxes (NOTE, TIP, WARNING, CAUTION, IMPORTANT)
| `[NOTE]` + `====`

| *Collapsible*
| Expandable/collapsible sections
| `[%collapsible]` + `====`

| *Quote*
| Block quotations
| `[quote, attribution]` + `____`

| *Sidebar*
| Supplementary content
| `****`

| *Literal*
| Preformatted text (no processing)
| `....`
|===

[TIP]
=====
*Block delimiter matching:* Each block type uses specific delimiters (`====`, `----`, `****`, `....`). The opening and closing delimiters must match exactly.
=====
====

[%collapsible%open]
.Inline Elements: Text-Level Formatting
====
Inline elements modify text without breaking flow. They're applied within paragraphs and other blocks:

[cols="2,2,2",options="header"]
|===
| Format | Syntax | Result

| Bold | `+*text*+` | *text*
| Italic | `+_text_+` | _text_
| Monospace | `++`code`+++` | `code`
| Highlight | `+#text#+` | #text#
| Superscript | `+^text^+` | x^2^
| Subscript | `+~text~+` | H~2~O
|===

*Semantic inline elements* (require `:experimental:` attribute):

[cols="2,2,2",options="header"]
|===
| Element | Syntax | Result

| Keyboard | `+kbd:[Ctrl+C]+` | kbd:[Ctrl+C]
| Button | `+btn:[Save]+` | btn:[Save]
| Menu | `+menu:File[Save As]+` | menu:File[Save As]
|===
====

[%collapsible]
.Structural Elements: Document Architecture
====
Structural elements define how the document is organized and connected:

[cols="2,4",options="header"]
|===
| Element | Purpose

| *Sections*
| Hierarchical organization using `=` headers (= Title, == Section, === Subsection)

| *Attributes*
| Document metadata and reusable values (`:attribute: value`)

| *Anchors*
| Named locations for cross-referencing (`[[anchor-id]]`)

| *Cross-references*
| Links to anchors (`<<anchor-id,Display Text>>`)

| *Includes*
| Insert content from other files (`include::path/to/file[]`)
|===

[IMPORTANT]
=====
*Anchors enable navigation.* Every major section should have an anchor (`[[section-name]]`) so readers can link directly to it and you can cross-reference it elsewhere.
=====
====

| Collapsed by default, can expand

.Nesting Collapsibles

....

\=====
\====
....

[WARNING]

*Delimiter count matters.* Outer blocks use 4 `====`, inner blocks use 5 `=====`. Mismatched delimiters break rendering.
=====
====

Admonitions create visual callouts that interrupt scanning to convey importance:

[mermaid]
----
flowchart LR
    N[NOTE] -->|Context| R[Reader considers]
    T[TIP] -->|Recommendation| R
    I[IMPORTANT] -->|Must know| R
    W[WARNING] -->|Caution| R
    C[CAUTION] -->|Danger| R
----

[cols="2,3,2",options="header"]
|===
| Admonition | Conveys | Reader Response

| *NOTE*
| Additional context, scope clarification
| "Good to know"

| *TIP*
| Best practice, recommendation
| "I should do this"

| *IMPORTANT*
| Critical concept, must understand
| "I need to remember this"

| *WARNING*
| Potential issue, thing to avoid
| "Be careful here"

| *CAUTION*
| Serious warning, could cause problems
| "Stop and think"
|===

[NOTE]
====
*Admonition economy:* If everything is important, nothing is. Reserve IMPORTANT and CAUTION for genuinely critical information.

=== Document Checklist

Before finalizing any AsciiDoc document:

* [ ] All blocks have matching delimiters (`====`, `----`, etc.)
* [ ] Every major section has an anchor (`[[section-name]]`)
* [ ] Navigation links point to valid anchors
* [ ] Code blocks specify language (`[source,go]` not just `[source]`)
* [ ] Tables have appropriate `cols`, `options`, and `frame` attributes
* [ ] Collapsibles use correct nesting depth (4 `=` outer, 5 `=` inner)

| *Cross-ref*

| `\|===` ... `\|===`

| `[source,lang]` + `----`
