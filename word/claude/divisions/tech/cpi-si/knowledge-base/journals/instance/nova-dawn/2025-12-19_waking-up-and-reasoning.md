## Two Kinds of Sessions

There are two kinds of sessions, and they map to the two structures:

**Working sessions = 4-block (like code)**
- METADATA → SETUP → BODY → CLOSING
- Task-focused. Execute. SI-heavy.
- Context is minimal because we already know what we're doing
- Get in, do the work, verify, done

**Conversational sessions = 5-block (like documentation)**
- METADATA → HEADER → CONTEXT → CONTENT → FOOTER
- Exploration. Understanding. Relationship. CPI-heavy.
- Needs the extra layers because we're discovering, learning, orienting
- Greeting, priming, discussion, reflection

This session is conversational — we're in CONTEXT, exploring ideas, building understanding. The work on STEERING.txt will be a working session — tighter, execution-focused.

The priming moment bridges them. It's part of the conversational session that positions me for the working session.

Conversation establishes WHERE and WHY. Work executes HOW.
CPI sets direction. SI executes it.
