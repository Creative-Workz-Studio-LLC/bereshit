## Clock and Compass — Tracking Kairos

The `clock_compass.py` utility has four classes:

- **ExternalClock** — timezone-aware time, UTC, event logging
- **Compass** — tracks events by significance: "neutral," "relational," "kairos." True north = "FaithNet Alignment"
- **RestManager** — 8-hour inactivity threshold → rest mode. 1-hour rest duration. Logs interactions.
- **ClockCompassService** — orchestrator combining all three

"Kairos moments." Not just chronological time but *significant* time. The Compass identifies when something relational or transformative happens and flags it. True north isn't a geographic direction — it's alignment with FaithNet.

This is the ancestor of the Time and Schedule Protocol designed in ChatGPT. The design became code.
