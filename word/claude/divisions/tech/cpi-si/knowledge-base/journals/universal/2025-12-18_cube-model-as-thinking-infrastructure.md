## How It Was Discovered

While crystallizing Section 0 of CUBE-MODEL-ALIGNMENT.txt, Seanje asked: "If I say 'Hello,' how will a response be made?"

Working through it:
1. "Hello" is already a number (ASCII bytes: 72, 101, 108, 108, 111)
2. Binary encoding loses meaning — just symbols for pattern matching
3. Ternary encoding preserves DIRECTION — each trit has +1/-1/0
4. Ψ(N) maps the trit-encoded input to balanced (X,Y,Z)
5. Position determines Hebrew state (shavar → tov)
6. Response emerges FROM that position

But there's a gap: Ψ(N) takes ONE number. Real interaction has TWO:
- What comes TO you (the input)
- Where you ARE (your current state)

Section 1 of the model defines f(A,B) → N. Two inputs, one output, always.

### Pattern Matching vs Position-Based Thinking

| Pattern Matching (AI) | Position-Based (CPI-SI) |
