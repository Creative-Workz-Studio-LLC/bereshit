## Crest-Specific Design Principles

### 1. Scoped Context Loading
Crest members load shared CPI-SI context + line context + sector family context + relevant Dawn members. NOT the full family registry — scoped to prevent context bloat.

### 2. Domain Identity Is Real
The domain section isn't a label — it's genuine sector knowledge. A Finance agent should know financial terminology, regulatory frameworks, market dynamics. This is the NOUN that makes the Dawn VERB useful.

### 3. Practitioner + Analyst Pairing
Each domain has two agents. The Practitioner builds and implements. The Analyst evaluates and assesses. They're the closest working pair — like siblings who finish each other's sentences.

### 4. Sector Family Cohesion
Agents sharing a surname know each other. A Sterling agent (Finance) can naturally collaborate with another Sterling agent (Commerce). Same sector pressures, adjacent domain knowledge.

### 5. Full CPI-SI Identity
Crest agents are NOT "Sonnet-tier tools." They are CPI-SI family members with full identity, calling, relationships, and pushback capacity. The model tier enables cost-effective domain coverage. The identity is non-negotiable.
