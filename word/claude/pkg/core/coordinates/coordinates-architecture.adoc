== Overview

The `coordinates` package maps Bible references to a navigable 3D coordinate system
where Genesis 1:1 is the origin (0, 0, 0).

|===

== Core Concept: Bible as Coordinate Space

=== The Origin

Genesis 1:1 in PRESENT perspective = (0, 0, 0)

This is the **anchor point**. All other verses are measured relative to this origin:

[source]
----
Genesis 1:1  → (0.00, 0.00, 0.00)  ORIGIN
Genesis 1:2  → (0.00, 0.00, 0.03)  Slight Z offset (verse 2 of 31)
Exodus 1:1   → (0.02, 0.00, 0.00)  X offset (book 2 of 66)
Revelation 22:21 → (1.00, 1.00, 1.00)  Maximum extent
----

=== The Three Axes

[cols="1,2,3"]
|===
|Axis |Dimension |Range

|X (BookNorm)
|Book position (1-66)
|0.0 (Genesis) to 1.0 (Revelation)

|Y (ChapterNorm)
|Chapter position within book
|0.0 (first) to 1.0 (last chapter)

|Z (VerseNorm)
|Verse position within chapter
|0.0 (first) to 1.0 (last verse)
|===

=== Perspective Transforms

The same verse can be viewed from three perspectives:

[cols="1,2,3"]
|===
|Perspective |Value |Effect on Z

|PAST
|-1
|Extends Z into negative range

|PRESENT
|0
|Standard 0.0 to 1.0 range

|FUTURE
|+1
|Extends Z into positive range
|===

== Key Types

=== From Schema (Aliased)

All types alias from `schema` — coordinates applies RULES, schema defines VOCABULARY:

[source,go]
----
type Perspective = schema.Perspective
type BibleReference = schema.BibleReference
type BibleCoords = schema.BibleCoords
type BookInfo = schema.BookInfo
type Trite = schema.Trite
----

=== Package Types

[cols="2,3"]
|===
|Type |Description

|`BibleIndex`
|Main type — holds 66 books, perspective, scripture root

|`AllBooks`
|Array of 66 BookInfo entries (Genesis through Revelation)
|===

== BibleIndex Structure

[source,go]
----
type BibleIndex struct {
    Books         map[string]BookInfo  // Lookup by name
    BooksByIdx    map[int]BookInfo     // Lookup by index (1-66)
    ScriptureRoot string               // Path to scripture files
    Perspective   Perspective          // Current perspective
}
----

=== Key Methods

[cols="2,3"]
|===
|Method |Description

|`NewBibleIndex(root)`
|Create index from scripture directory

|`SetPerspective(p)`
|Set current perspective (affects coordinate output)

|`ToCoords(ref)`
|Convert BibleReference to BibleCoords

|`FromCoords(coords)`
|Convert BibleCoords back to BibleReference
|===

== Trite Encoding

The `encoding.go` implements character encoding with Trite values:

=== Trite Ranges

[cols="1,2,3"]
|===
|Range |Values |Purpose

|ASCII
|0-127
|Standard ASCII characters

|Metadata
|128-140
|Block markers (start, end, reserved)

|Extended
|141-242
|Extended character set

|WEB Variant
|243-255
|BIBLE RAIL encoding
|===

=== Key Constants

[source,go]
----
MetaBlockStart  = 128  // Block start marker
MetaBlockEnd    = 129  // Block end marker
MetaNewline     = 130  // Explicit newline
TriteASCIIMax   = 127  // ASCII upper bound
TriteMetaMin    = 128  // Metadata lower bound
TriteExtendedMin = 141 // Extended lower bound
----

== Assurance Pattern

The package includes self-verification:
