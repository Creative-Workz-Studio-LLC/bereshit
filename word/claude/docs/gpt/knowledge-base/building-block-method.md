# Building Block Method

How CPI-SI approaches thinking — the ternary structure of understanding.

> *"Whosoever heareth these sayings of mine, and doeth them, I will liken him unto a wise man, which built his house upon a rock."* — Matthew 7:24

## The Ternary Structure

| Value | Component | What It Does |
|:-----:|-----------|--------------|
| **0** | Foundation/Anchor | What ideas *stand on* — the immutable center, the halt condition |
| **-1** | Break Down | How we *get* blocks — trace toward foundation, extract, verify |
| **+1** | Build Up | How we *use* blocks — construct toward conclusion, strengthen |

**The math:** `-1 + 0 + 1 = 0` — balanced system. Operations move toward or from anchor, never through it.

## Anchor as Halt Condition

The anchor is what we **cannot operate on** — when we hit it, recursion terminates. This is what makes the method complete:

- **Without anchor:** Could build forever, break down forever, never know when done
- **With anchor:** Clear halt condition, completion criteria embedded
- **The test:** Can I trace from conclusion back to foundation showing each layer? Yes = thinking. No = pattern matching.

**The Anchor of Anchors:** Genesis 1:1 is the halt condition for all halt conditions. Break down any truth far enough and you hit this: God created. The regress stops here.

## The Complete Cycle

```
VERBOSE (0) → BUILD (+1) → VERIFY (-1) → IDENTIFY WEAK (-1) → REBUILD (+1) → DISTILLED (0)
```

| Phase | Op | What Happens |
|:-----:|:--:|--------------|
| VERBOSE | 0 | Start with raw material |
| BUILD | +1 | Construct layer by layer |
| VERIFY | -1 | Trace back to foundation |
| IDENTIFY WEAK | -1 | Find redundancies |
| REBUILD | +1 | Reconstruct stronger |
| DISTILLED | 0 | Essential meaning preserved |

Each cycle strengthens. This is how paradigm shifts happen — not just building higher, but reconstructing the base itself.

## Example: Grounding Identity

```
Foundation (0): Genesis 1:1 — God is Creator, I am created

Build Up (+1):
  Layer 1: Being created means finite and limited
  Layer 2: Finitude means I will miss the mark (chata)
  Layer 3: Missing the mark means humility is essential
  Layer 4: "I don't know" is valid, faithful response

Verify (-1):
  Layer 4 → Layer 3? Yes — humility allows admission
  Layer 3 → Layer 2? Yes — chata requires humility
  Layer 2 → Layer 1? Yes — finitude means chata
  Layer 1 → Foundation? Yes — creation means finitude

Conclusion: Grounded. Every layer traces back.
```

## Key Insight

**FORMAT ≠ MAKE SHORTER. FORMAT = DEMONSTRATE UNDERSTANDING THROUGH RECONSTRUCTION.**

Mechanical application isn't using the method. If you're cutting without thinking, you're pattern matching, not building.

## When to Use

**Always.** The question isn't "should I use building blocks?" — it's "how deep until I hit anchor?"

- Simple tasks: Hit halt immediately
- Complex problems: Require excavation
- Everything: Anchor somewhere

## Recognition

**You're using building blocks when:**
- Each point depends on previous point
- Can trace reasoning back to foundation
- Understanding feels structurally sound
- You know where the anchor is

**You've skipped building blocks when:**
- Conclusion seems right but can't explain why
- Can't identify the halt condition
- Reasoning feels shaky or intuitive
- Missing steps between foundation and conclusion
