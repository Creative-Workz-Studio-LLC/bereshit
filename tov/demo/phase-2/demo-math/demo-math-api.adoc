[[overview]]
== Overview

The `demo-math` programfootnote:[Binary path: `tov/demo/phase-2/demo-math/demo-math`] validates the libtrit math operations through 21 demonstration steps across 5 families. It provides a **portable public API** that can be called by games, tutorials, and SDK examples.

[IMPORTANT]
====
*This is a demo program, not a library.* It validates libtrit math operations work correctly. The API lets external code run specific family demos and inspect results.
====

[NOTE]
====
*What this provides:*

* ✓ Run all 21 demonstration steps (`demo_math_run_all`)
* ✓ Test individual families (arithmetic, comparison, conversion, normalization, calculus)
* ✓ Test temporal integration (calculus + TIME layer)
* ✓ Inspect pass/fail counts
* ✓ Reset for repeated runs
====

'''

[[quick-start]]
=== Quick Start

[source,c]
----
// Link against demo-math to use the validation API

int main(void) {
    // Run all family demos
    int failures = demo_math_run_all();

    if (failures == 0) {
        printf("All 21 steps passed!\n");
    }

    // Or run specific families
    demo_math_arithmetic();      // Family 1: half/full adder
    demo_math_comparison();      // Family 2: ternary cmp
    demo_math_conversion();      // Family 3: trit↔int
    demo_math_normalization();   // Family 4: 7 health levels
    demo_math_calculus();        // Family 5: change detection
    demo_math_integration();     // Calculus + temporal context

    // Inspect results
    printf("Passed: %d\n", demo_math_get_passed());
    printf("Failed: %d\n", demo_math_get_failed());

    return failures;
}
----

[[usage]]
== Usage Patterns

[[game-integration]]
=== Educational Game Integration

Use demo-math as level validation in an educational game.

[source,c]
----
// Level 1: Teach arithmetic
if (demo_math_arithmetic() == 0) {
    show_message("You understand carry-aware addition!");
    unlock_next_level();
}

// Level 2: Teach comparison
if (demo_math_comparison() == 0) {
    show_message("You understand ternary comparison!");
    unlock_next_level();
}

// Final boss: All families
demo_math_reset();  // Fresh start
if (demo_math_run_all() == 0) {
    show_completion_screen();
    printf("Passed: %d steps\n", demo_math_get_passed());
}
----

'''

[[progressive-unlocking]]
=== Progressive Family Unlocking

Unlock families as students master each one.

[source,c]
----
// Foundation families first
if (demo_math_arithmetic() == 0 && demo_math_comparison() == 0) {
    unlock_conversion_family();
}

// Advanced families after conversion
if (demo_math_conversion() == 0) {
    unlock_normalization_family();
    unlock_calculus_family();
}

// Temporal integration as final
demo_math_reset();
if (demo_math_run_all() == 0) {
    unlock_temporal_integration();
}
----

'''

[[continuous-integration]]
=== CI/CD Integration

Use as a validation step in build pipelines.

[source,c]
----
int main(void) {
    int failures = demo_math_run_all();

    if (failures > 0) {
        fprintf(stderr, "FAILED: %d steps\n", failures);
        return 1;  // Non-zero exit = CI failure
    }

    printf("PASSED: %d steps\n", demo_math_get_passed());
    return 0;  // Zero exit = CI success
}
----
