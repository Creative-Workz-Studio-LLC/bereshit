[[running-it]]
== Running the Demo

[.lead]
{the-proof}

[TIP]
====
*Before you begin:* Ensure you have the <<prerequisites,prerequisites>> in place — Go 1.23+ and the Bereshit repository cloned.
====

=== Build & Run

****
[.lead]
*How to execute the demo:*

[source,bash]
----
cd tov/demo/phase-0/demo-config

make build      # Build to bin/demo-config
make run        # Build and run
make test       # Run and verify exit code
make diagnostic # Run comprehensive loader diagnostic
make status     # Show current state
----

[horizontal]
icon:cog[] *`make build`*:: Compile the demo binary to `bin/demo-config`
icon:play[] *`make run`*:: Build and execute — see the output
icon:check[] *`make test`*:: Run and verify exit code (CI-friendly)
icon:stethoscope[] *`make diagnostic`*:: Deep diagnostic — useful for debugging
icon:info-circle[] *`make status`*:: Show current build state
****

=== Understanding the Output

****
[.lead]
*What the status codes mean:*

.Ternary Status Values
[cols="^1,^1,4",options="header,autowidth",frame="topbot"]
|===
| Status | Value | Meaning

| icon:check-circle[] PASS
| `+1`
| Primary path works — `index.toml` manifests load successfully

| icon:exclamation-circle[] HALF PASS
| `0`
| Fallback works — tripwire triggered, but specs still valid

| icon:times-circle[] FAIL
| `-1`
| System broken — check `make diagnostic` for details
|===

.Exit Codes
[cols="^1,4",options="header,autowidth",frame="topbot"]
|===
| Code | Meaning

| `0`
| icon:check[] Status is PASS or HALF PASS — {phase} validated

| `1`
| icon:times[] Status is FAIL — run `make diagnostic` for details
|===
****
