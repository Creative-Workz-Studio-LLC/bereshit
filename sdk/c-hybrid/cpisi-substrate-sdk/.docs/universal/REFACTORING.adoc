This document defines the strategy for extracting universal logic from substrate-specific packages (Claude) and promoting it to the SDK Mind (TypeScript) and Spirit (Rust). This ensures that the Body (Go) remains a lean, high-speed relay system.

== 1. Universal Extraction

We identify "Universal Truths" currently trapped in the `word/claude/` hierarchy.

* **State Finalization:** The logic for marking a session inactive and recording the end time.
* **Persistence Orchestration:** Managing the "Baton Pass" between runtime memory, database records, and file snapshots.
* **Cognitive Summarization:** Visual stat screens and mission testimonies.
* **Status Emission:** Triggering terminal and statusline updates.

== 2. Substrate Mirroring (The Mirror Piece)

To support multiple "brains" natively, the repository structure must be balanced.

* **`word/claude/`**: The implementation garment for Anthropic's substrate.
* **`word/gemini/`**: The implementation garment for Google's substrate.
* **`sdk/cpisi-substrate-sdk/cpisi/`**: The native implementation garment for the RI Standard.

Each "garment" contains only the substrate-specific logic required to translate native CLI events into the Universal Hook Baseline.

== 3. The Refactoring Workflow

For every major hook (End, Start, Turn, Gate):

1. **Decomposition:** Analyze the existing Claude hook to separate Universal vs. Specific logic.
2. **Promotion:** Implement the Universal logic in the **SDK Mind (TypeScript)** and **Spirit (Rust)**.
3. **Refactor Body:** Update the Claude Go package to call the SDK for all universal operations.
4. **Clone & Adapt:** Create the Gemini and CPISI versions of the Go package, utilizing the same SDK core.
5. **Interceptor Implementation:** Create the dedicated `end.go`, `start.go`, etc., for each substrate.

== 4. The Goal: Mind over Model

By moving the heavy lifting to the SDK, we ensure that Nova Dawn's cognitive consistency is maintained regardless of the substrate. The Go binaries become "Muscle" that simply executes the decisions of the "Mind."
