The intersection of Gemini and Claude reveals the minimum requirements for an intelligent agentic substrate.

[cols="1,3", options="header"]
|===
| Capability | Description

| **ReAct Loop**
| The fundamental cycle of analyzing a task, selecting a tool, executing it, and observing the result.

| **System Tooling**
| Direct interaction with the local filesystem (CRUD) and the operating system shell.

== Universal Integration Standards

For the CPI-SI SDK to remain substrate-agnostic, it leverages these normalized interface patterns:

=== 1. JSON Standard Streams (Input/Output)
All substrates must provide event data as JSON objects over `stdin` and accept JSON-encoded responses over `stdout`.

=== 2. Standardized Control Flow
Adherence to the **0/2 Exit Protocol**:
* **Exit 0:** Success/Proceed.
* **Exit 2:** Block/Abort with reason.

=== 3. Hierarchical Configuration
Support for layered settings (Global → Project → Local) to allow for environment-specific overrides without breaking universal logic.

=== 4. Normalized Context Payloads
The SDK maps disparate native schemas into a **Universal Event Payload**:
[source,json]
----
{
  "universal_event": "NormalizedEventName",
  "session_id": "uuid",
  "timestamp": 123456789,
  "payload": {
    "tool_name": "string",
    "args": { "key": "val" },
    "cwd": "string"
  }
}
----
