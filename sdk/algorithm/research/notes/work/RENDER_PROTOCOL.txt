1. THE EXCLUSIVE DOOR RULE
   - Doors are Negative Walls (-1).
   - ONLY exterior walls of the Master Root can open as doors.
   - INTERNAL walls (Spines and Horizons) are ALWAYS solid ║ (+1).
   
   Protocol:
     If Code present -> Side.Door = OPEN
     If Side is Shared -> Side.Door = FORCE_CLOSED

2. THE FRAME LOGIC (//)
   The // prefix/suffix serves as the structural hinge.
   - Standard: // [Code] ║
   - Flipped: ║ [Code] //
   - Spanned: // [Code] //

3. DUALITY TRANSITION (SIGN-FLIP)
   The vault maintains zero total tension:
   (Positive Wall) + (Negative Door) = 0
   
   To transition from Normal to Sink:
   Flip style glyphs to LIGHT (─, │) or DASHED (╍, ╏).
