# OmniCode 2D Structural Width Formula (Base)

# Formula:
$W_{total} = C_{omni\_prefix} + W_{dynamic\_content}$

# Constants & Variables:
*   $W_{total}$: Total effective visual width of the outermost container (characters).
    *   Current empirically derived value: 152 characters (from `sdk/src/main.rs`).

*   $C_{omni\_prefix}$: Constant length of the `#!omni:` prefix (characters).
    *   Immutable value: 8 characters (from `sdk/blankspace/pragma_details.txt`).

*   $W_{dynamic\_content}$: Maximum dynamic content width to the right of the `#!omni:` prefix (characters).
    *   Current empirically derived value: 144 characters (calculated as $W_{total} - C_{omni\_prefix}$).

# Derivation:
This formula establishes the absolute horizontal boundary for OmniCode-compliant files. The `C_{omni\_prefix}` serves as the fixed left anchor, while `W_{dynamic\_content}` represents the maximum horizontal space available for all subsequent nested containers and functional code within the file's main structural vault. This ensures perfect right-hand wall alignment.
