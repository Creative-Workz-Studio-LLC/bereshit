# OmniCode 2D Structural Width Formula (Full Derivation)

# Core Formula:
$W_{container} = P_L + W_{content} + P_R + B_R$

# Where:
*   $W_{container}$: The total visual width of any given container (characters).
    *   (Derived dynamically based on content and nesting level.)

*   $P_L$: Internal Left Padding (indentation of executable code within inner containers).
    *   Immutable value: 12 characters (from `sdk/blankspace/structural_constants.txt`).

*   $W_{content}$: The maximum visual width of the *pure functional code content* within a container (characters).
    *   (Derived dynamically for each container.)

*   $P_R$: Internal Right Padding (spaces between functional code and the trailing `// ║` wall).
    *   (Derived dynamically to ensure $L_C = R_C$ for each container.)

*   $B_R$: Trailing Border Width (width of `// ║` itself, assuming 1 space before `//`).
    *   Immutable value: 4 characters (from `sdk/blankspace/structural_constants.txt`).

# Additional Constants & Relationships:
*   $W_{root\_canvas}$: Total effective visual width of the outermost `[BLOCK:ROOT]` container (characters).
    *   Current empirically derived value: 152 characters.

*   $C_{omni\_prefix}$: Constant length of the `#!omni:` prefix (characters).
    *   Immutable value: 8 characters (from `sdk/blankspace/pragma_details.txt`).

*   $\Delta P_{right}$: The difference in right padding between $W_{root\_canvas}$ and the deepest line's total span.
    *   Empirically derived value: 35 characters (from `sdk/blankspace/blankspace.adoc`).

# Derivation Philosophy:
This comprehensive formula allows for the dynamic calculation of container widths, ensuring geometric perfection and visual balance across all nesting levels. It explicitly incorporates the internal padding and border metrics, making the seemingly aesthetic choices mathematically rigorous. The ultimate goal is to maintain a visually balanced composition where the left-hand spacing ($L_C$) equals the right-hand spacing ($R_C$) for each container, relative to the outermost `W_{root\_canvas}`.
