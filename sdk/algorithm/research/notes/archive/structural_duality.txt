# Structural Duality: The Door and The Wall

# Perspective 1: Symmetrical Balance (V1)
- The code sits in the center of the vault.
- The "Firmament" is distributed evenly on both sides.
- Result: A stable, "Tic-Tac-Toe" board aesthetic.

# Perspective 2: Flipped Asymmetry (V2)
- The left side is the "Opening Door" (Gap = delta_G = 33).
- The right side is the "Absolute Wall" (Gap = 0, Walls = Solid Stack).
- Result: A receding corridor aesthetic where the functional code "activates" the opening.

# The Logic of the Flip:
The Flipped perspective allows the functional code to act as the midpoint of the visual experience. The eye enters from the wide left-hand portal and is stopped by the immutable right-hand wall. This contrast provides the handiest visual aid for navigating complex code hierarchies.
