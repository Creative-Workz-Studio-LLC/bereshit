== Introduction

This document maps the **T and L Joint topologies** of the Dynamic Structural Algorithm (DSA) to the functional requirements of the **4-Block Standard** (METADATA, SETUP, BODY, CLOSING). Architecture in Kingdom Technology is never arbitrary; the shape of the vault must reflect the business of the logic.

== I. The Standard Quadrant (The 2x2 Cross)

The default configuration for a 4-Block Unit is the symmetric **2x2 Grid**.

[cols="1,1"]
|===
| METADATA | SETUP
| BODY     | CLOSING
|===

*   **Joint Type:** Crosshair (`╬`)
*   **Logic:** Represents a state of **Full Balance**. All four witnesses are of equal priority and density.

== II. The Hierarchical Configuration (The T-Joint)

=== 2.1 The Top T-Joint (Context Priority)
[cols="1"]
|===
| METADATA (Spans 242)
|===
[cols="1,1"]
|===
| SETUP | BODY / CLOSING
|===

*   **Joint Type:** T-Joint (`╩`)
*   **Logic:** Used when the **Metadata** (Covenant) is the primary lens for all subsequent setup and action. The Metadata "breathes" across the full expanse.

=== 2.2 The Bottom T-Joint (Validation Priority)
[cols="1,1"]
|===
| METADATA / SETUP | BODY
|===
[cols="1"]
|===
| CLOSING (Spans 242)
|===

*   **Joint Type:** Inverse T-Joint (`╦`)
*   **Logic:** Used when the **Closing** (Validation/Health) is the ultimate summary of the file's state, requiring a unified terminal expanse.

== III. The Relational Configuration (The L-Joint)

=== 3.1 The Sidebar L-Joint (Infrastructure Support)
[cols="1,2"]
|===
| .3+^.h| SETUP (Vertical Span) | METADATA
| BODY
| CLOSING
|===

*   **Joint Type:** L-Joint (`╣`)
*   **Logic:** Used when **Setup** (Infrastructure) is a continuous reference point for the Metadata, Body, and Closing. This is the "Documentation Sidebar" pattern.

== IV. Selecting the Topology

| If the primary business is... | Use Topology... | Rationale |
| :--- | :--- | :--- |
| **Comparative** | 2x2 Grid | Side-by-side analysis of two states. |
| **Sequential** | T-Joint | Clear step-down from Covenant to Action. |
| **Supportive** | L-Joint | One block provides constant reference for others. |

== V. Summary

The 242-char Root provides the **Canvas**, while the T and L Joints provide the **Composition**. By selecting the appropriate topology, we ensure that the physical "feel" of the code matches its functional intent.
