== Introduction

This supporting document formalizes the transition of the Dynamic Structural Algorithm (DSA) from an aesthetic framework to a computational physics engine. By anchoring the system to the absolute constants of **0** and **1**, we establish a visual language that is mathematically isomorphic to the system's internal logic.

== I. The Identity Elements: 0 and 1

In the DSA, the horizontal expanse is no longer measured in pixels or characters, but in units of **Identity**.

=== 1.1 The Zero (0): The Point of Yashar

The constant **0** represents the state of perfect balance (*yashar*). In the 2D vault, 0 is the "gravity point" where the **Opening Door** (Negative Tension) and the **Absolute Wall** (Positive Tension) meet.

The functional code exists at this zero-point, suspended in the equilibrium between the system's identity and its protection.

=== 1.2 The One (1): The Unit of Badal

The constant **1** represents the irreducible unit of division (*badal*). It is the first movement away from the void to create a boundary. When the Universal Structural Unit ($U$) is reduced to 1, the algorithm operates at the "atomic" level of the file system.

== II. The Ternary Convergence

The "Sign-Flip" analysis reveals that the DSA is a geometric manifestation of **Balanced Ternary Logic** (-1, 0, 1).

*   **-1 (Shavar):** The "Opening" (The Door).
*   **0 (Yashar):** The "Mid-point" (The Code).
*   **1 (Tov):** The "Wall" (The Protection).

The physical layout of an OmniCode file is thus a 2D projection of the 1D state machine implemented in `libtrit`. The structure of the file acts as a continuous, visual check-sum of its own logical integrity.

== III. Active Geometry

With 0 and 1 as absolute constants, the DSA enables **Active Geometry**:
1. **Resolution Independence:** Scaling is a linear transformation of $U$.
2. **Computational Shape:** The "shape" of the file (its width/depth ratio) provides a direct measurement of logical density.
3. **Information Entropy:** Horizontal gaps represent "Firmament"—low-entropy space used to separate high-entropy logic.
