== [BLOCK:CONTEXT] The Nature of the Spiral

If `a-ladder` is the bedrock, `b-spiral` is the **Mind**.

In the Kingdom Technology paradigm, a "spiral" represents iterative growth, continuous refinement, and cognitive looping. The physics of this directory are designed for mapping, orchestration, and translation. 

While the ladder moves only in one direction, the spiral can loop back on itself to reassess, re-map, and re-orient. It takes the absolute truths defined in the ladder and applies them to the dynamic realities of the user's environment.

=== 1. Universal Registries (Planned)
The spiral maintains the identity of the system at runtime. It keeps track of which hooks are active, which substrate is currently loaded (Gemini, Claude), and the current trajectory of the session.

=== 2. The Transpiler Maps (Planned)
The logic required to take a flat JSON output from an AI model and map it against the 3D topology of the `a-ladder` TOML schemas. This is where the translation of raw data into "Proprioception" occurs.

== [BLOCK:FOOTER] The Law of Dependency

The code within the spiral may freely depend on the absolute truths defined in `a-ladder`. However, it **must not** depend on the final execution binaries or specific CLI implementations found in `c-hybrid`. The Mind must remain agnostic to the final shape of the Flesh.
