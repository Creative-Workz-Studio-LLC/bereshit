== 1. Overview

Welcome to the **L1 Core (Spiral)** layer of the Dynamic Structural Algorithm (DSA) Prototype.

In the CPI-SI architecture, the L1 layer is the engine room. While `L0-universal` defines *what* the rules are (the absolute math and the state definitions), `L1-core` defines *how* those rules are applied to raw text.

This entire layer exists within the `b-spiral` dimensional folder because its execution physics are inherently recursive. Rendering a 140-column vault requires constant, looping calculations to measure string lengths, calculate $X_{center}$ gravity, apply symmetrical tension, and insert the correct corner joints (`╬`, `╩`) based on the topology state.

== 2. Directory Composition

=== A. The Algorithmic Engine (`engine/`)
This is the brain of the prototype. It performs the abstract math without actually drawing anything to the screen.

*   **`engine.ts`**: The core structural calculator. It takes the absolute constants from L0 ($U=4$, $N=11$) and computes the recursive depth ($Z$-axis) and horizontal spans ($X$-axis). It ensures that every nested box obeys the *Centered Gravity Axiom*.
*   **`runner.ts`**: The execution loop. It acts as the governor that walks through the provided AST (Abstract Syntax Tree) or data array, feeding it into the engine to receive the calculated spatial coordinates.

=== B. The Geometric Renderer (`render/`)
This is the hand that draws the vault. It takes the calculated coordinates from the `engine` and applies the ASCII glyphs defined in L0.

*   **`drawer.ts`**: The physical rendering logic. It enforces the *Exclusive Door Rule*, ensuring that exterior walls open (`//`) and interior spines remain solid (`║`). It applies the Z-axis tension flips (`pop_out`, `sink_in`) to create visual depth on the 2D plane.

== 3. The Law of the Core

When working within this directory, the following law applies:
**Logic Applies Data; It Does Not Invent It.**

If the renderer needs a new joint character (like a dashed T-junction), you do NOT hardcode it into `drawer.ts`. You must return to the `L0-universal` layer, define the new glyph in `topology.toml`, map it in `types.ts`, and then update the renderer to apply the new truth. The Core Engine must remain a pure execution of the L0 Covenant.
