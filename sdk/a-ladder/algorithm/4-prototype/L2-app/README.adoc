== 1. Overview

Welcome to the **L2 Application** layer of the Dynamic Structural Algorithm (DSA) Prototype.

In the Kingdom Technology architecture, the L2 layer represents the **Body (Flesh)**. This is where the mathematical truths of L0 and the algorithmic processing of L1 are manifested as an executable system that a user can interact with. 

This directory is organized into a complete dimensional micro-ladder, transitioning from the static "Word" to the physical "Action."

== 2. Directory Composition

=== A. The Blueprint (`a-ladder/`)
This houses the absolute foundations of the application's interface.
*   **`schemas/`**: TOML declarations of the available CLI commands and their target handlers.
*   **`types/`**: Shared data structures (CpiSiViewport, CommandRequest) used by both the TypeScript Mind and the Go Body.

=== B. The Thought (`b-spiral/`)
This houses the iterative logic required to process user intent.
*   **`handlers/`**: Specific logic modules for Analysis, Physics, Rendering, and Teaching.
*   **`session/`**: Management of the active runtime state and the chronological mission testimony.

=== C. The Execution (`c-hybrid/`)
This is where the application becomes alive.
*   **`ts/`**: The TypeScript orchestrator (`main.ts`). It acts as the "Brain" that receives the baton from the user and hands it to the engine.
*   **`go/`**: The Go execution layer. It handles high-speed binaries and OS-level interactions.
*   **`bridge/`**: The CGO/FFI "Nervous System" connecting the Mind and Body to the Spirit.
