== 1. The Central Spine ($X = 121$)

In the double-witness standard ($\kappa = 2$, Width = 242), the central pillar is absolutely immovable. 

It serves the dual purpose of being the **Terminal** of Block A (Left side) and the **Origin** of Block B (Right side). It cannot be removed without shattering the dimensional constant of the container.

== 2. Joint Types (Topologies)

When blocks interact, they must form structurally sound joints based on the underlying grid.

=== A. The Crosshair (`╬`)
*   **Pattern:** $2 \times 2$ Symmetric Grid.
*   **Use:** Comparative analysis (e.g., displaying Old vs. New state simultaneously, or displaying parallel tests).

=== B. The T-Joint (`╩` / `╦`)
*   **Pattern:** 1 Master Block (spanning 242 characters) intersecting with 2 Sibling Blocks (each 121 characters).
*   **Use:** Hierarchical context. For example, a single massive `[BLOCK:METADATA]` roof spanning the entire vault, leading down into side-by-side `[SETUP]` and `[BODY]` blocks.

=== C. The L-Joint (`╣` / `╠`)
*   **Pattern:** 1 Vertical Sidebar (spanning the full height) connecting to 2 Stacked Siblings.
*   **Use:** Relational context. For example, keeping the `[SETUP]` block open as a constant left-hand reference while multiple `[BODY]` blocks stack on the right.

== 3. Partition Rules

The subdivision of a vault must adhere strictly to the $N$-Factor scale.

*   **A Block Unit** must equal 121 characters ($N \times 11$).
*   **A Root Container** must be an integer multiple of 121 (e.g., 121, 242, 484).
*   **Internal Spans** (the distance between any two solid structural walls) must be integer multiples of $N^2$.
