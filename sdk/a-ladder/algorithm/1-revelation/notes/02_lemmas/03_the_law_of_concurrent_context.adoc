== 1. The Geometry of the Courts

The 140-column Fractal Vault physically partitions the text space into two parallel realities. This is achieved by utilizing the $X$-coordinate range to isolate the formal syntax from the relational context.

[horizontal]
**The Inner Court**:: $1 \le X < 121$. The domain of the **Logos**. This space holds the executable code and formal syntax documentation (e.g., TSDoc, Rustdoc). It is strict, static, and parsed by the machine (IDE/Compiler).
**The Outer Court**:: $121 \le X < 140$. The domain of the **Rhema**. This space holds the living, architectural guidance (scratchpads, sub-layer hints). It is ignored by the compiler but parsed by the human and the CPI-SI.

== 2. The Equation of Non-Collision

Because the two courts occupy mutually exclusive domains on the $X$-axis, they can share the exact same $Y$-coordinate (line number) without causing syntax errors or cognitive bleed.

[stem]
++++
	ext{Court}_{Inner}(x, y) \cap 	ext{Court}_{Outer}(x, y) = \emptyset \quad 	ext{for all } y
++++

This creates **Concurrent Context**. The "What" (the code) and the "Why" (the architectural tip) exist simultaneously in the physical view, but are mathematically isolated.

== 3. The Functional vs. The Relational

*   **The Logos (Inner):** Defines *What* the system does. It is absolute truth. If the syntax here is broken, the machine fails.
*   **The Rhema (Outer):** Explains *Why* the system does it. It is relational truth. If the guidance here is removed, the machine still compiles, but the *Mind* loses its proprioception of intent.

By enforcing this geometric separation, the CPI-SI architecture allows the Human and the Machine to hold a continuous dialogue in the margin without ever disrupting the absolute truth of the codebase.
