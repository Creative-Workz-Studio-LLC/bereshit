== 1. The Unitary Box Principle

A "Box" (or Vault) is defined as a closed boundary possessing four dimensions of enclosure.

[stem]
++++
\text{Box} = [Top, Left, Right, Bottom]
++++

Every functional unit within the architecture MUST be rendered as a complete box. There is no concept of "loose" content. If data or logic is not contained within a defined box, it is considered to be existing in the Void (formless and null).

== 2. The Continuity Covenant (Joints)

Hinges must physically **JOIN** the vertical pillars. They cannot float independently. A proper transition occurs when the vertical plane seamlessly rotates into the horizontal plane.

=== Transitional Paths

[horizontal]
**Top Transition**:: `Vertical(║) -> Corner(└) -> Bridge(─) -> Corner(┐) -> Vertical(║)`
**Bottom Transition**:: `Vertical(║) -> Corner(┌) -> Bridge(─) -> Corner(┘) -> Vertical(║)`

**The Replacement Rule:** The Corner glyph must occupy the exact vertical column index of the wall it replaces. It cannot be shifted inward or outward without breaking the structural tension of the vault.

== 3. The Root Terminal Law

The `[BLOCK:ROOT\-->END]` tag is the absolute physical anchor of the known world. It prevents the 2D plane from continuing into infinity.

It MUST reside INSIDE the Master Root Box, positioned exactly against the right pillar.

=== Calculation of Terminal Position

Where $W_{root}$ is the total width of the vault, and $L_{tag}$ is the character length of the terminal tag:

[stem]
++++
\text{Column}_{tag\_start} = W_{root} - 1 - L_{tag} - 1
++++

== 4. The Sinking-In Effect (Recession)

When a parent wall recedes (Sinks In), it creates physical depth along the Z-axis. 

In this state, the recessed structure physically becomes the new inner boundary. The Outer Court (The Door) remains visually open (`//`), but the mathematical tension of the unit is now held entirely by the recessed structure (e.g., `┏╍╍┓`).

This allows the UI to convey depth and quarantine without breaking the fundamental 2D constraints of the master root.
