[.lead]
This document provides *practical alignment questions* for testing whether decisions, partnerships, projects, and team members align with {company-short} mission and vision.

[sidebar]
.icon:star[] Why This Document Matters
****
Abstract statements must become *concrete tests*. These questions translate mission and vision into practical decision-making tools that anyone in {company-short} can apply.
****

== icon:file-alt[] Document Purpose

[quote, Amos 3:3 (KJV)]
____
Can two walk together, except they be agreed?
____

[NOTE]
.icon:lightbulb[] Core Principle

*Alignment Is Practical:* Mission and vision statements are only useful if they guide real decisions. These questions translate statements into practical tests.
====

=== icon:tasks[] Process

|===
|icon:tag[] |Step |Action

|icon:search[role=blue]
|*1. Identify Type*
|What kind of decision is this? (Partnership, project, strategic, etc.)

|icon:list-ul[role=green]
|*2. Select Questions*
|Use the relevant question set

|icon:check[role=purple]
|*3. Answer Honestly*
|Don't rationalize — be truthful

|icon:balance-scale[role=orange]
|*4. Evaluate*
|What do the answers reveal?

|icon:gavel[role=gold]
|*5. Decide*
|Proceed, modify, or decline based on answers

[cols="^1,2,4",options="header",frame=all,grid=all]

|icon:tag[] |Red Flag |What It Indicates

|*Rationalizing "yes" when truth is "no"*
|Desire overriding alignment

|icon:exclamation-triangle[role=orange]
|*"Yes, but..."*
|Partial alignment — may need modification

|icon:question-circle[role=blue]
|*Unable to answer clearly*
|May need more information
