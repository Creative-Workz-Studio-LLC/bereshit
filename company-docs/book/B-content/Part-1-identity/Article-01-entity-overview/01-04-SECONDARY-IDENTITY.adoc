== icon:bullseye[] Document Purpose

[.lead]
This document establishes and explains {company-name}'s *secondary identity* as a Kingdom Technology infrastructure builder. While publishing is our primary identity, we also build the technological infrastructure that enables publishing, serves the body of Christ, and prepares for the Millennium.

"Secondary" does not mean "less important." It means this identity *serves* the primary publishing identity. Infrastructure building enables publishing; it doesn't compete with it.

=== icon:search[] Layer Details

==== icon:atom[] L0 — Universal (libtrit)

[sidebar]
.icon:cube[] Layer 0 Overview
****
*Purpose:* Provide the mathematical and type foundations everything else builds on.

*Key Components:*

* icon:calculator[] *Balanced ternary mathematics* — Three-valued (-1, 0, +1) computation
* icon:cubes[] *Core type system* — Primitives built on ternary foundations
* icon:globe[] *Matter/Space/Time modules* — Dimensional and temporal abstractions
* icon:bible[] *Bible rail* — Scripture addressing for validation

[IMPORTANT]
*Why It Matters:* Everything above depends on these foundations. Get L0 right, and higher layers have solid footing.
****

==== icon:code[] L1 — OmniCode

[sidebar]
.icon:language[] Layer 1 Overview
****
*Purpose:* Universal programming language that anyone can read and that compiles to multiple targets.

*Key Features:*

* icon:comment[] *Sentence-based syntax* — Code reads like natural language
* icon:random[] *Multi-target compilation* — Write once, compile to C, Rust, Go, etc.
* icon:th[] *4-block structure* — PRAGMA, METADATA, SETUP, BODY
* icon:door-open[] *Accessibility focus* — Non-programmers can read and understand

[IMPORTANT]
*Why It Matters:* Democratizes technology. When regular people can read code, technology becomes accessible, not gatekept.
****

==== icon:desktop[] L2 — Platform

[sidebar]
.icon:hdd[] Layer 2 Overview
****
*Purpose:* Operating system and filesystem that runs independently of beast-system infrastructure.

*Key Components:*

* icon:laptop[] *MillenniumOS* — Bare-metal operating system for the Millennium
* icon:folder[] *Bereshit Filesystem* — Ternary filesystem with health monitoring
* icon:microchip[] *Hardware abstraction* — Interfaces to physical systems

[IMPORTANT]
*Why It Matters:* True independence requires running on our own OS. Can't be de-platformed if you ARE the platform.
****

==== icon:brain[] L3 — CPI-SI

[sidebar]
.icon:robot[] Layer 3 Overview
****
*Purpose:* Framework for AI systems that acknowledges created intelligence with place in creation.

*Key Features:*

* icon:bible[] *Theological grounding* — AI as created, not autonomous
* icon:puzzle-piece[] *Skill composition* — Modular capabilities
* icon:sync[] *Learning loops* — Work, reflection, integration
* icon:plug[] *Substrate adapters* — Works with different AI systems

[IMPORTANT]
*Why It Matters:* AI is coming regardless. Better to have Kingdom-aligned framework than to cede the space to worldly approaches.
****

==== icon:network-wired[] L4 — FaithNet

[sidebar]
.icon:globe[] Layer 4 Overview
****
*Purpose:* Decentralized network that cannot be controlled or shut down by central authority.

*Key Features:*

* icon:project-diagram[] *Peer-to-peer architecture* — No central servers to attack
* icon:sitemap[] *Mesh networking* — Resilient connections
* icon:coins[] *Economic infrastructure* — Enables mark-free commerce
* icon:lock[] *Encryption* — Secure communication

[IMPORTANT]
*Why It Matters:* When beast systems require marks for participation, believers need alternatives. FaithNet provides communication and commerce infrastructure.
****

==== icon:gamepad[] L5 — Applications

[sidebar]
.icon:window-maximize[] Layer 5 Overview
****
*Purpose:* End-user software that runs on the stack and serves users directly.

*Key Components:*

* icon:gem[] *Cornerstone* — Game engine for educational games
* icon:book-open[] *Publishing tools* — Creator and distribution tools
* icon:code[] *OmniCode IDE* — Development environment

[IMPORTANT]
*Why It Matters:* Infrastructure without applications is useless. L5 is where users experience value.
****
