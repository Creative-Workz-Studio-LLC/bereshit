== icon:ban[] Anti-Patterns

=== icon:user-graduate[] Expert-Only

[sidebar]
.icon:exclamation-triangle[] Warning: Expert-Only
****
*What It Is:*

Creating things only experts can understand — code, documentation, products that assume advanced knowledge.

*Why It Violates Teaching:*

Teaching reaches learners, not just experts. Expert-only work excludes the people who most need to learn.

*Warning Signs:*

* icon:times-circle[role=red] "They should already know this"
* icon:times-circle[role=red] Jargon without explanation
* icon:times-circle[role=red] Documentation that assumes expertise
* icon:times-circle[role=red] Products requiring extensive prior knowledge
* icon:times-circle[role=red] Impatience with beginners
****

=== icon:file-excel[] Undocumented

[sidebar]
.icon:exclamation-triangle[] Warning: Undocumented
****
*What It Is:*

Creating without documenting — code without comments, processes without explanation, products without guides.

*Why It Violates Teaching:*

Undocumented work can't teach beyond direct interaction. It dies with its creator. It hoards knowledge.

*Warning Signs:*

* icon:times-circle[role=red] "I'll document it later"
* icon:times-circle[role=red] Tribal knowledge only
* icon:times-circle[role=red] New people can't onboard easily
* icon:times-circle[role=red] Original creators must explain everything
* icon:times-circle[role=red] Knowledge lost when people leave
****

=== icon:hourglass-end[] Teaching as Afterthought

[sidebar]
.icon:exclamation-triangle[] Warning: Teaching as Afterthought
****
*What It Is:*

Adding documentation or teaching later, after the product is "done" — treating teaching as optional extra.

*Why It Violates Teaching:*

Afterthought documentation is usually incomplete, disconnected, and quickly outdated. Teaching should be designed in, not added on.

*Warning Signs:*

* icon:times-circle[role=red] Documentation phase at end of project
* icon:times-circle[role=red] Teaching materials created by different team
* icon:times-circle[role=red] Products that don't naturally teach
* icon:times-circle[role=red] Constant documentation backlog
* icon:times-circle[role=red] "We'll add tutorials later"
****

'''
