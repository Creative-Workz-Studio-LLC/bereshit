== icon:ban[] Anti-Patterns

=== icon:user-slash[] Isolation

[sidebar]
.icon:exclamation-triangle[] Warning: Isolation
****
*What It Is:*

Operating as independent entity without community connection — self-sufficient in way that precludes mutual support.

*Why It Violates Mutual Support:*

Isolation prevents both giving and receiving support. It rejects the Body model. It misses the strength of community.

*Warning Signs:*

* icon:times-circle[role=red] "We don't need anyone"
* icon:times-circle[role=red] No network participation
* icon:times-circle[role=red] Relationships purely transactional
* icon:times-circle[role=red] No support given or received
* icon:times-circle[role=red] Independence valued over interdependence
****

=== icon:hand-holding-usd[] Extraction

[sidebar]
.icon:exclamation-triangle[] Warning: Extraction
****
*What It Is:*

Taking from community more than giving — using network for benefit without reciprocating.

*Why It Violates Mutual Support:*

Mutual support requires mutuality. Taking without giving breaks community. It parasitizes rather than participates.

*Warning Signs:*

* icon:times-circle[role=red] Receiving help but not giving
* icon:times-circle[role=red] Taking referrals but not making them
* icon:times-circle[role=red] Using network resources without contributing
* icon:times-circle[role=red] Relationships only when beneficial to {company-short}
* icon:times-circle[role=red] "What's in it for us?"
****

=== icon:toggle-off[] Conditional Support

[sidebar]
.icon:exclamation-triangle[] Warning: Conditional Support
****
*What It Is:*

Supporting others only when convenient, beneficial, or reciprocated — withdrawing support when difficult.

*Why It Violates Mutual Support:*

True mutual support continues through difficulty. Conditional support isn't really support — it's transaction.

*Warning Signs:*

* icon:times-circle[role=red] Support withdrawn when inconvenient
* icon:times-circle[role=red] Help only for "valuable" partners
* icon:times-circle[role=red] Abandoning struggling members
* icon:times-circle[role=red] Expectations of immediate reciprocity
* icon:times-circle[role=red] Calculating ROI on every support act
****

'''
