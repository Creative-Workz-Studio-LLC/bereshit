= Assets Directory
:icons: font

This directory contains visual assets for the CWS Company Identity Manual.

== Required Assets

[cols="2,3,2",options="header"]
|===
| Filename | Purpose | Specifications

| `cws-logo.png`
| Company logo for cover and title pages
| Recommended: 600x600px, transparent background

| `cws-logo-dark.png`
| Logo variant for dark backgrounds (optional)
| Same dimensions as primary logo

| `cws-icon.png`
| Small icon for headers/footers (optional)
| 64x64px or 128x128px
|===

== Logo Requirements

Per the brand guidelines in `01-entity-overview/01-02-NAME-AND-BRAND.adoc`:

* *Clean, professional design* suitable for print and digital
* *Readable at small sizes* (favicons, headers)
* *Transparent background* for flexible placement
* *Embodies*: Craftsmanship, faith foundation, creativity, professionalism

1. Place files in this directory
2. Use exact filenames referenced in documents
3. Rebuild the manual: `make html` or `make pdf`
