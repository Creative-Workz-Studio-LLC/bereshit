== icon:exchange-alt[] Transaction Types

=== icon:sync[] Direct Barter

[cols="^1,2,4",options="header",frame=all,grid=all]
|===
|icon:tag[] |Aspect |Description

|icon:book[role=blue]
|*Definition*
|Immediate exchange of goods/services between two parties — no money involved

|icon:cogs[role=green]
|*Mechanism*
|Party A provides X, Party B provides Y — direct exchange, immediate

|icon:balance-scale[role=purple]
|*Value Determination*
|Mutual agreement on equivalence — both parties agree it's fair

|icon:file-alt[role=orange]
|*Documentation*
|Record of exchange for both parties — essential for accountability and taxes

|icon:check-circle[role=gold]
|*Use Case*
|When both parties have complementary needs — the classic trade scenario

|===

==== icon:file-invoice[] Barter Example

[source]
----
BARTER EXAMPLE:

    Party A (Web Developer)          Party B (Accountant)

    ┌─────────────────────┐         ┌─────────────────────┐
    │                     │         │                     │
    │  Has: Web skills    │         │  Has: Tax skills    │
    │  Needs: Tax help    │   ◄►    │  Needs: Website     │
    │                     │         │                     │
    └─────────────────────┘         └─────────────────────┘

    Exchange: Website work (valued $X) for Tax work (valued $X)

    Result: Both needs met, no money exchanged
----

=== icon:coins[] Trade Credits

[cols="^1,2,4",options="header",frame=all,grid=all]
|===
|icon:tag[] |Aspect |Description

|icon:book[role=blue]
|*Definition*
|Network-internal value units accumulated for later use

|icon:cogs[role=green]
|*Mechanism*
|Provide service, receive credits; use credits for services from others

|icon:gem[role=purple]
|*Value Basis*
|Credits represent value provided to network — earning through contribution

|icon:star[role=orange]
|*Benefit*
|Enables exchange when direct barter doesn't match — flexibility

|icon:check-circle[role=gold]
|*Use Case*
|When needs don't directly align between two parties

|===

==== icon:file-invoice[] Trade Credits Example

[source]
----
TRADE CREDITS EXAMPLE:

    Month 1: Party A provides web services to Party B
             Party A receives 100 credits
             Party B uses credits

    Month 3: Party A needs accounting services from Party C
             Party A uses 100 credits
             Party C receives 100 credits

    Result: A served B, C served A — credits enabled the exchange
----

=== icon:sync-alt[] Reciprocal Services

[cols="^1,2,4",options="header",frame=all,grid=all]
|===
|icon:tag[] |Aspect |Description

|icon:book[role=blue]
|*Definition*
|Ongoing exchange relationships between parties — not one-time, but continuous

|icon:cogs[role=green]
|*Mechanism*
|Regular provision of services in both directions — mutual support over time

|icon:balance-scale[role=purple]
|*Value Balance*
|Roughly equivalent over time, not per transaction — relationship, not bean-counting

|icon:file-alt[role=orange]
|*Documentation*
|Relationship agreement, periodic true-up — clear expectations

|icon:check-circle[role=gold]
|*Use Case*
|Long-term relationships with ongoing mutual needs

|===

==== icon:file-invoice[] Reciprocal Services Example

[source]
----
RECIPROCAL SERVICES EXAMPLE:

    Party A (IT Support)            Party B (Legal Services)

    ┌─────────────────────┐         ┌─────────────────────┐
    │                     │         │                     │
    │  Provides: Monthly  │ ◄────►  │  Provides: Quarterly│
    │  IT support         │         │  legal review       │
    │                     │         │                     │
    └─────────────────────┘         └─────────────────────┘

    Annual Agreement: Ongoing exchange, valued approximately equal

    Result: Both have ongoing support without ongoing payments
----
