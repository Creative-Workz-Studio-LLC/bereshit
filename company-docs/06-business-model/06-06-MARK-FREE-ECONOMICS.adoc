== Transaction Types

=== Direct Barter

[cols="1,3",options="header"]
|===
|Aspect |Description

|*Definition*
|Immediate exchange of goods/services between two parties

|*Mechanism*
|Party A provides X, Party B provides Y — direct exchange

|*Value Determination*
|Mutual agreement on equivalence

|*Documentation*
|Record of exchange for both parties

|*Use Case*
|When both parties have complementary needs

|===

==== Barter Example

[source]
----
BARTER EXAMPLE:

    Party A (Web Developer)          Party B (Accountant)

    ┌─────────────────────┐         ┌─────────────────────┐
    │                     │         │                     │
    │  Has: Web skills    │         │  Has: Tax skills    │
    │  Needs: Tax help    │   ◄►    │  Needs: Website     │
    │                     │         │                     │
    └─────────────────────┘         └─────────────────────┘

    Exchange: Website work (valued $X) for Tax work (valued $X)

    Result: Both needs met, no money exchanged
----

=== Trade Credits

[cols="1,3",options="header"]
|===
|Aspect |Description

|*Definition*
|Network-internal value units accumulated for later use

|*Mechanism*
|Provide service, receive credits; use credits for services from others

|*Value Basis*
|Credits represent value provided to network

|*Benefit*
|Enables exchange when direct barter doesn't match

|*Use Case*
|When needs don't directly align between two parties

|===

==== Trade Credits Example

[source]
----
TRADE CREDITS EXAMPLE:

    Month 1: Party A provides web services to Party B
             Party A receives 100 credits
             Party B uses credits

    Month 3: Party A needs accounting services from Party C
             Party A uses 100 credits
             Party C receives 100 credits

    Result: A served B, C served A — credits enabled the exchange
----

=== Reciprocal Services

[cols="1,3",options="header"]
|===
|Aspect |Description

|*Definition*
|Ongoing exchange relationships between parties

|*Mechanism*
|Regular provision of services in both directions

|*Value Balance*
|Roughly equivalent over time, not per transaction

|*Documentation*
|Relationship agreement, periodic true-up

|*Use Case*
|Long-term relationships with ongoing mutual needs

|===

==== Reciprocal Services Example

[source]
----
RECIPROCAL SERVICES EXAMPLE:

    Party A (IT Support)            Party B (Legal Services)

    ┌─────────────────────┐         ┌─────────────────────┐
    │                     │         │                     │
    │  Provides: Monthly  │ ◄────►  │  Provides: Quarterly│
    │  IT support         │         │  legal review       │
    │                     │         │                     │
    └─────────────────────┘         └─────────────────────┘

    Annual Agreement: Ongoing exchange, valued approximately equal

    Result: Both have ongoing support without ongoing payments
----

=== Resource Sharing

[cols="1,3",options="header"]
|===
|Aspect |Description

|*Definition*
|Shared access to resources among network members

|*Mechanism*
|Pool resources, share access and costs

|*Examples*
|Equipment, facilities, software licenses, bulk purchasing

|*Benefit*
|Access to resources individually unaffordable

|*Use Case*
|Resources needed occasionally but expensive to own

|===

=== Gift Economy

[cols="1,3",options="header"]
|===
|Aspect |Description

|*Definition*
|Provision without expectation of specific return

|*Mechanism*
|Give according to ability, receive according to need

|*Biblical Basis*
|Acts 2:44-45 pattern within Body of Christ

|*Complement*
|Works alongside exchange systems, not replacement

|*Use Case*
|Emergency needs, those unable to exchange

|===

'''
