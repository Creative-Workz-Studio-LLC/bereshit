== Document Purpose

This document details the *four revenue streams* that sustain Creative Workz Studio — External Creative Partnerships, Internal IP Revenue, Services & Fees, and Trade Network Value. Each stream is examined for mechanics, growth trajectory, and Kingdom alignment.

[quote, Ecclesiastes 11:2 (KJV)]
____
Give a portion to seven, and also to eight; for thou knowest not what evil shall be upon the earth.
____

[NOTE]
====
*Diversification as Wisdom:* Multiple revenue streams aren't just good business — they're biblical wisdom. CWS doesn't depend on any single source, reducing vulnerability and enabling consistent mission service.
====

'''

== Stream 1: External Creative Partnerships

=== Overview

[source]
----
EXTERNAL CREATIVE PARTNERSHIPS:

    ┌─────────────────┐
    │   CREATIVE      │  Artist, developer, writer, etc.
    │   PARTNER       │  Creates work
    └────────┬────────┘
             │
             ▼
    ┌─────────────────┐
    │      CWS        │  Marketing, publication,
    │   PUBLISHES     │  distribution, support
    └────────┬────────┘
             │
             ▼
    ┌─────────────────┐
    │   REVENUE       │  Sales, licensing, etc.
    │   GENERATED     │
    └────────┬────────┘
             │
        ┌────┴────┐
        │         │
        ▼         ▼
    ┌───────┐ ┌───────┐
    │CREATOR│ │  CWS  │
    │ SHARE │ │ SHARE │
    │       │ │       │
    │(larger│ │(based │
    │  %)   │ │ on    │
    │       │ │support│
    │       │ │level) │
    └───────┘ └───────┘
----

=== Mechanics

[cols="1,3",options="header"]
|===
|Element |How It Works

|*Source*
|Sales and distribution of creative partner works

|*Revenue Generation*
|Direct sales, licensing, subscriptions, merchandise

|*Split Determination*
|Support level chosen by creator (Full/Moderate/Light/Infrastructure)

|*Payment Timing*
|Per agreement terms, typically after sales cycle

|*Creator Ownership*
|Creator retains 100% IP ownership always

|===

=== Support Level Splits

[cols="1,2,2,2",options="header"]
|===
|Support Level |CWS Services |CWS Share |Creator Share

|*Full Support*
|Complete marketing, production, distribution, consultation
|Higher %
|Lower %

|*Moderate Support*
|Significant help in key areas, creator handles others
|Medium %
|Medium %

|*Light Support*
|Guidance and QA, creator executes
|Lower %
|Higher %

|*Infrastructure Only*
|Platform and tool access, minimal involvement
|Minimal %
|Majority %

|===

[NOTE]
====
Specific percentages are negotiated per partnership. The framework ensures both fair compensation for CWS services and meaningful returns for creators.
====

=== Growth Trajectory

[cols="1,3",options="header"]
|===
|Phase |Characteristics

|*Early Stage*
|Few partners, intensive relationship development, building portfolio

|*Growth Stage*
|Partner acquisition accelerates, systems mature, referrals increase

|*Mature Stage*
|Stable partner base, recurring revenue, focus shifts to partner success

|*Scaling Stage*
|Portfolio generates consistent returns, selective new partnerships

|===

=== Kingdom Alignment

[cols="1,3",options="header"]
|===
|Alignment Factor |How It's Maintained

|*Creator Ownership*
|IP retention is non-negotiable — Kingdom-aligned

|*Values Filtering*
|Only aligned creatives become partners

|*Success Alignment*
|CWS only earns when partners earn

|*Autonomy Respect*
|Creator direction honored; we support, don't control

|===

For detailed partnership model, see <<../02-publishing-house-model/02-02-EXTERNAL-CREATIVES.adoc#,External Creatives>>.

----

=== Trade Types

[cols="1,2,2",options="header"]
|===
|Type |Description |Example

|*Direct Barter*
|Immediate exchange of services
|CWS builds website, receives graphic design

|*Trade Credits*
|Accumulated value for later exchange
|CWS earns credits from Partner A, uses with Partner B

|*Reciprocal Services*
|Ongoing exchange relationships
|Annual website maintenance for annual bookkeeping

|*Resource Sharing*
|Shared access to assets
|Shared equipment, pooled software licenses

|===

=== Mechanics

[cols="1,3",options="header"]
|===
|Element |How It Works

|*Value Determination*
|Mutual agreement on exchange value

|*Documentation*
|Clear records of trades and credits

|*Network Scope*
|Kingdom-aligned businesses in trade network

|*Dispute Resolution*
|Good-faith negotiation, network arbitration

|===

=== Why Trade Network Matters

[cols="1,3",options="header"]
|===
|Benefit |Explanation

|*Mark-Free Capability*
|Commerce possible without beast-system financial infrastructure

|*Community Building*
|Network strengthens relationships

|*Resource Efficiency*
|Exchange what you have for what you need

|*Resilience*
|Multiple ways to transact if one fails

|===

=== Kingdom Alignment

[cols="1,3",options="header"]
|===
|Alignment Factor |How It's Maintained

|*Preparation*
|Building infrastructure for prophetic realities

|*Community*
|Strengthening Body of Christ connections

|*Justice*
|Fair exchange without exploitation

|*Generosity*
|Network includes gift economy elements

|===

== Revenue Mix Target

=== Ideal Diversification

[cols="1,1,2",options="header"]
|===
|Stream |Target Range |Rationale

|35-45%
|Relational, aligned growth, primary identity

|25-35%

|Ranges allow adaptation to conditions

|===
