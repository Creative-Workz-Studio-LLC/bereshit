## The Name: What It Means

### Creative
Made in the image of the Creator. Creativity is a divine attribute reflected in His image-bearers. We create because He created first.

### Workz
Labor with purpose. Works as faith made visible. The 'z' marks distinction from corporate sterility—this is different. Not just work, but workz that matter.

## Primary Identity: Publishing House

CWS is first and foremost a **publishing house**. This means:

1. **We help creatives publish their work** across all media types
2. **We build and publish our own intellectual properties** (games, software, media)
3. **We provide infrastructure** that enables publishing at scale
4. **We connect creatives** with marketing, distribution, and consultation resources

The publishing house model is the business. Everything else flows from this identity.

This infrastructure serves our publishing mission and is offered to the broader body of Christ.

## Repository Structure

CWS operates through a hierarchy of code repositories:

```
CWS Repo (Creative Workz Studio — company level)
└── Bereshit Repo (Kingdom Technology foundation)
    ├── CPI-SI for Claude Repo (AI integration, shareable)
    └── Cornerstone Repo (game engine)
```

Each repository can function independently while contributing to the whole. This submodule architecture enables:

- Independent development of components
- Sharing of specific modules with external parties
- Clear ownership and versioning boundaries
- Collaboration without entanglement
