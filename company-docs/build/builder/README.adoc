=== What This Does

The CWS Manual Builder takes the AsciiDoc source files that comprise the Company Identity Manual and compiles them into publication-ready formats:

[cols="^1,2,4",options="header",frame=all,grid=all]
|===
| icon:file[] Format | Extension | Purpose

| icon:globe[role=blue] HTML
| `.html`
| Web-ready single-page document with embedded styles, navigation, and searchability

| icon:file-pdf[role=red] PDF
| `.pdf`
| Print-ready document with professional typography, headers, footers, and page numbers

| icon:book[role=green] EPUB
| `.epub`
| E-reader format for Kindle, Apple Books, Kobo, and other digital reading devices

| icon:code[role=purple] DocBook
| `.xml`
| XML interchange format for integration with other documentation systems
|===

=== Why TypeScript

The build system is written in TypeScript for several reasons:

* *Type Safety* — Catches configuration errors at compile time
* *Modern Tooling* — Integrates with Node.js ecosystem
* *Readable Code* — Clear structure for future maintenance
* *No Python* — Avoids dependency on Python runtime

The TypeScript code orchestrates the Asciidoctor CLI tools (written in Ruby) which perform the actual document conversion.

== icon:code[] Programmatic Usage

The build system can be imported as a library for integration into other tools:

[source,typescript]
----
import {
  createBuilder,
  loadConfig,
  type OutputFormat
} from '@cws/manual-builder';

// Load configuration with optional overrides
const config = loadConfig({
  outputDir: './custom-output',
});

// Create builder with event callback
const builder = createBuilder(config, (event) => {
  switch (event.type) {
    case 'start':
      console.log('Building formats:', event.formats);
      break;
    case 'format-complete':
      console.log(`${event.result.format}: ${event.result.success ? 'OK' : 'FAILED'}`);
      break;
    case 'complete':
      console.log('Build complete');
      break;
  }
});

// Build specific formats
const results = await builder.build(['html', 'pdf']);

// Or build all formats in parallel
const allResults = await builder.buildParallel();

// Watch for changes
builder.startWatch(['html']);
----

=== Exported Types

[source,typescript]
----
// Configuration
type BuildConfig = {
  sourceDir: string;
  outputDir: string;
  masterDocument: string;
  outputName: string;
  attributes: Record<string, string>;
  formatOptions: FormatOptions;
};

// Output formats
type OutputFormat = 'html' | 'pdf' | 'epub' | 'docbook';

// Build result
type BuildResult = {
  format: OutputFormat;
  success: boolean;
  outputPath: string;
  duration: number;
  error?: string;
};
----

== icon:exclamation-triangle[] Troubleshooting

=== "asciidoctor: command not found"

The Asciidoctor tool is not installed or not in PATH.

*Solution:*

[source,bash]
----
# Install via gem
gem install asciidoctor

# Or via system package manager:
# Ubuntu/Debian
sudo apt install asciidoctor

# macOS
brew install asciidoctor
----

=== "asciidoctor-pdf: command not found"

The PDF converter is not installed.

*Solution:*

[source,bash]
----
gem install asciidoctor-pdf
----

=== "asciidoctor-epub3: command not found"

The EPUB converter is not installed.

*Solution:*

[source,bash]
----
gem install asciidoctor-epub3
----

=== Ruby gem Permission Errors

Cannot install gems due to permission restrictions.

*Solution:*

[source,bash]
----
# Use user installation
gem install asciidoctor --user-install

# Or configure gem for user directory
echo 'gem: --user-install' >> ~/.gemrc
----

=== Build Completes But Output Missing

The build reported success but files are not in the output directory.

*Possible Causes:*

1. Wrong working directory — run from `company-docs/`
2. Output directory permissions
3. Disk space issues

*Solution:*

[source,bash]
----
# Check output directory
ls -la output/

# Rebuild with verbose output
cd builder && node dist/cli.js --format html
----

=== Watch Mode Not Detecting Changes

Files are being modified but watch mode doesn't rebuild.

*Possible Causes:*

1. File is outside watched directories
2. File extension not `.adoc` or `.asciidoc`
3. Editor using atomic saves (writes to temp file first)

*Solution:*

Watch mode monitors `**/*.adoc` and `**/*.asciidoc` in the source directory. Ensure your files have these extensions.
