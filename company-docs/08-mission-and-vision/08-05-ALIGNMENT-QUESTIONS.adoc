== Document Purpose

This document provides *practical alignment questions* for testing whether decisions, partnerships, projects, and team members align with CWS mission and vision. These questions make abstract statements concrete and actionable.

[quote, Amos 3:3 (KJV)]
____
Can two walk together, except they be agreed?
____

[NOTE]
====
*Alignment Is Practical:* Mission and vision statements are only useful if they guide real decisions. These questions translate statements into practical tests.
====

'''

== Mission Alignment Questions

=== Core Mission Test

For any opportunity, partnership, or decision:

[cols="1,3",options="header"]
|===
|Question |What "Yes" Means

|"Does this publish or equip creatives?"
|Advances primary identity

|"Does this preserve creator ownership and autonomy?"
|Protects non-negotiable

|"Does this build Kingdom-aligned infrastructure?"
|Advances secondary identity

|"Does this serve the body of Christ?"
|Serves primary audience

|"Does this prepare mark-free alternatives?"
|Advances preparation mission

|"Does this serve the world to come?"
|Maintains eternal perspective

|===

=== If Any Answer Is "No"

[source]
----
MISSION ALIGNMENT CHECK:

    Ask all six questions
            │
            ▼
    ┌───────────────────────┐
    │ All answers "Yes"?    │
    └───────────┬───────────┘
                │
        ┌───────┴───────┐
        │               │
        ▼               ▼
      YES              NO
        │               │
        ▼               ▼
    Proceed to     ┌───────────────────────┐
    values test    │ Can it be modified    │
                   │ to align?             │
                   └───────────┬───────────┘
                               │
                       ┌───────┴───────┐
                       │               │
                       ▼               ▼
                     YES              NO
                       │               │
                       ▼               ▼
                   Modify          DECLINE
                   and re-test
----

== Using Alignment Questions

=== Process

[cols="1,3",options="header"]
|===
|Step |Action

|*1. Identify Type*
|What kind of decision is this? (Partnership, project, strategic, etc.)

|*2. Select Questions*
|Use the relevant question set

|*3. Answer Honestly*
|Don't rationalize — be truthful

|*4. Evaluate*
|What do the answers reveal?

|*5. Decide*
|Proceed, modify, or decline based on answers

|===

=== Red Flags in Answers

[cols="1,3",options="header"]
|===
|Red Flag |What It Indicates

|*Rationalizing "yes" when truth is "no"*
|Desire overriding alignment

|*"Yes, but..."*
|Partial alignment — may need modification

|*Unable to answer clearly*
|May need more information

|*Answers change depending on audience*
|Integrity issue

|*Discomfort with questions*
|May indicate misalignment

|===
