= Editorial Style Guide
:company-name: CreativeWorkzStudio LLC

== The Standard

[quote, Seanje Lenox-Wise]
____
PhD-level formatting and rigor in terms of presentation. Formalize future
conglomerate-level documentation. But the language and tone should be like
the Bible — rich but accessible. It should feel like the company's heart
on every page.
____

*Three tests for every page:*

. *PhD rigor* — Would this pass a doctoral committee's formatting review?
. *Bible accessibility* — Can a shepherd scan it AND a scholar study it?
. *Company heart* — Does this page feel like CreativeWorkzStudio?


== Page Anatomy

Every content page in the cover follows this structure:

....
[.text-center]
[discrete]
=== Section Title                    <1>

[.text-center]
_Italic subtitle — one to two lines_ <2>

'''                                   <3>

[.text-center]                        <4>
Body content — centered, flowing

'''                                   <5>

[.text-center]
[.small]
_Closing note — governance weight_    <6>
....

<1> *Heading* — discrete `===` (h3), centered, renders in deep blue (Noto Sans)
<2> *Subtitle* — italic, centered, sets the tone for the page
<3> *Opening break* — thematic break separates header from body
<4> *Body* — centered flowing text, `[.text-center]` on every block
<5> *Closing break* — thematic break before the closing note
<6> *Closing note* — `[.small]` italic, often carries legal/governance weight

Not every page needs all six elements, but the pattern holds.


== Typography Rules

=== Text Alignment

[cols="2,3",options="header"]
|===
|Rule |Why

|*Everything centered*
|Publication style — not a tech doc. `[.text-center]` on every text block.

|*No justified text*
|Justified paragraphs break the centered flow. Convert to centered lines.

|*Line breaks with `+`*
|Use `+` at line ends for manual breaks within centered blocks.
|===

=== Font Styling

[cols="2,2,3",options="header"]
|===
|Style |Markup |Use For

|*Bold*
|`*text*`
|Labels, key phrases, emphasis (e.g., "**board-level governance**")

|*Italic*
|`_text_`
|Subtitles, scripture text, closing notes, audience labels

|*Bold + Italic*
|`*_text_*`
|Scripture commands (bold) within italic context

|*Small text*
|`[.small]` block attribute
|Closing notes, governance provisions, legal text, document metadata

|*Lead text*
|`[.lead]` block attribute
|Opening statements, key declarations, scripture emphasis

|*Big text*
|`[.big]` inline role
|Part numbers in the manual structure page
|===

=== Headings

[cols="2,3",options="header"]
|===
|Pattern |Usage

|`[discrete]` + `=== Title`
|Section titles within the cover — renders visually but stays out of TOC

|No `==` (h2) in cover
|The cover uses only `===` (h3) discrete headings for visual sections

|Deep blue color
|Headings render in #1A365D (from theme) — do not override
|===


== Structural Elements

=== Thematic Breaks

....
'''
....

* Separate the header zone (title + subtitle) from body content
* Separate body content from closing notes
* Separate major content sections within a page
* Do NOT use between every item in a list-like page (e.g., Core Values, Bereshit Stack layers) — spacing is sufficient

=== Page Breaks

....
// --- PAGE BREAK: Description (Page N) ---
<<<
....

* Comment before every page break identifying what follows
* The comment includes the page name and PDF page number
* Every section starts on a new page

=== Empty Line Spacers

....
{empty} +
....

* Use between items that need visual separation without a thematic break
* Common in the Bereshit Stack layers (L0, L1, etc.)
* Lighter separation than `'''`

=== Centered Blocks

....
[.text-center]
Text content here +
with line breaks.
....

* `[.text-center]` applies to the NEXT block element only
* Must be repeated for each paragraph/block
* Does NOT cascade to subsequent paragraphs


== Legal & Governance Language

=== Binding Provisions

Three instances of binding language reinforce legal weight:

. *Page 2 (Purpose)* — "board-level governance" + "expected to align"
. *Page 11 (Reading Guide)* — "carry the force of board-adopted policy upon execution of the Approval Chain"
. *Page 12 (Document Governance)* — "take effect upon execution of the Approval Chain and remain binding"

When adding new sections, maintain this pattern — significant governance
provisions should reference the Approval Chain as the activation mechanism.

=== Amendment Thresholds

Two thresholds, always stated together:

* *Majority vote* — standard changes and adoption
* *Unanimous consent* — core values, mission, or identity changes

These appear on pages 4, 10, and 12. Keep language consistent.

== Anti-Patterns

Things we removed during the cover editorial process:

[cols="2,3",options="header"]
|===
|Avoid |Use Instead

|*Icon tables* (`icon:shield[]` in table cells)
|Centered flowing text with bold labels

|*Multi-column tables* for content layout
|Centered text blocks separated by thematic breaks

|*TIP/IMPORTANT/NOTE admonition boxes*
|Centered text with bold labels and thematic breaks

|*Justified/left-aligned paragraphs*
|Centered text with `[.text-center]` + line breaks

|*"Chapter" language*
|"Article", "Section", "§" — governance terminology

|*Redundant logos*
|One logo on title page; no additional logos in cover body

|*"Creative Workz Studio LLC"* (spaced)
|"CreativeWorkzStudio LLC" (legal name, no spaces)

|*Closing filler* ("Continue to the next section...")
|Meaningful transition statements with governance framing

|*Dense paragraph blocks*
|Break into centered flowing lines — one thought per visual unit
|===

== Closing Note

This style guide captures the editorial standard established across the
fourteen cover pages. The pattern is:

* *Structure* — centered, flowing, publication-grade typography
* *Tone* — rich but accessible, like Scripture
* *Weight* — governance-ready, legally sound, conglomerate-formal
* *Heart* — every page should feel like CreativeWorkzStudio

When reviewing subsequent sections (Dedication, Preface, Glossary, Articles),
use this guide as the comparison baseline. Where existing content uses tables,
icons, admonition boxes, or justified text — convert to the centered flowing
style established here.

The quality comes from the careful time and effort, not from rushing to completion.
