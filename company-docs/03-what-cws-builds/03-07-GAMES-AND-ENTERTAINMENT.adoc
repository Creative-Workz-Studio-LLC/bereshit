[.lead]
This document covers {company-short}'s approach to *games and entertainment*—the philosophy behind our games, the Cornerstone engine foundation, and development goals for entertaining content that genuinely teaches.

[sidebar]
.icon:star[] Why This Document Matters
****
Most educational games fail because they're *educational first, games second*. {company-short} inverts this: games that are *genuinely fun* where learning happens naturally through play. This document explains how we achieve that goal.
****

[IMPORTANT]
.The Core Philosophy
====
*The Core Philosophy:* Games that are *actually fun* AND *actually help people learn*. Not edutainment that's boring with points. Real games with real learning integrated naturally.
====

'''

== icon:compass[] Game Philosophy

=== icon:exclamation-triangle[] The Problem with "Edutainment"

Most educational games fail because:

[cols="^1,2,4",options="header",frame=all,grid=all]
|===
|icon:tag[] |Problem |Description

|icon:frown[role=blue]
|*Fun is Afterthought*
|Educational goals drive design; fun is bolted on

|icon:pills[role=purple]
|*Obvious Teaching*
|Learning feels like taking medicine disguised as candy

|icon:layer-group[role=green]
|*Shallow Gameplay*
|Gameplay exists only to deliver curriculum

|icon:user-graduate[role=orange]
|*Patronizing Design*
|Treats players as receptacles for information

|icon:redo[role=red]
|*No Replay Value*
|Once you've "learned," no reason to return
|===

=== icon:check-circle[] The {company-short} Alternative

{company-short} games invert the typical approach:

[cols="^1,2,3,3",options="header",frame=all,grid=all]
|===
|icon:tag[] |Aspect |Typical Edutainment |{company-short} Games

|icon:bullseye[role=blue]
|*Primary Goal*
|Teach content
|Be genuinely fun

|icon:puzzle-piece[role=purple]
|*Learning Integration*
|Explicit, obvious
|Natural, emergent from play

|icon:layer-group[role=green]
|*Gameplay Depth*
|Shallow, serves curriculum
|Deep, engaging on its own

|icon:heart[role=orange]
|*Respect for Player*
|Player is student
|Player is participant

|icon:infinity[role=red]
|*Replayability*
|Low (content consumed)
|High (gameplay compelling)
|===

=== icon:gavel[] Design Principles

[cols="^1,2,4",options="header",frame=all,grid=all]
|===
|icon:tag[] |Principle |Application

|icon:star[role=blue]
|*Fun First*
|If it's not fun, it fails. No exceptions.

|icon:graduation-cap[role=purple]
|*Learning Through Play*
|Mechanics naturally teach concepts

|icon:brain[role=green]
|*Respect Intelligence*
|Don't dumb down or patronize

|icon:chess[role=orange]
|*Meaningful Choices*
|Player decisions matter

|icon:compass[role=red]
|*Natural Discovery*
|Learning emerges from exploration

|icon:cross[role=blue]
|*Kingdom Alignment*
|Content consistent with Kingdom values
|===

[TIP]
.The Fun Test
====
Before asking "Does this teach?", ask "Would someone play this even if it didn't teach anything?" If no, redesign until yes.
====

'''
