== Document Purpose

This document covers CWS's approach to *games and entertainment*—the philosophy behind our games, the Cornerstone engine foundation, and development goals for entertaining content that genuinely teaches.

[IMPORTANT]
====
*The Core Philosophy:* Games that are *actually fun* AND *actually help people learn*. Not edutainment that's boring with points. Real games with real learning integrated naturally.
====

'''

== Game Philosophy

=== The Problem with "Edutainment"

Most educational games fail because:

[cols="1,3",options="header"]
|===
|Problem |Description

|*Fun is Afterthought*
|Educational goals drive design; fun is bolted on

|*Obvious Teaching*
|Learning feels like taking medicine disguised as candy

|*Shallow Gameplay*
|Gameplay exists only to deliver curriculum

|*Patronizing Design*
|Treats players as receptacles for information

|*No Replay Value*
|Once you've "learned," no reason to return
|===

=== The CWS Alternative

CWS games invert the typical approach:

[cols="1,2,2",options="header"]
|===
|Aspect |Typical Edutainment |CWS Games

|*Primary Goal*
|Teach content
|Be genuinely fun

|*Learning Integration*
|Explicit, obvious
|Natural, emergent from play

|*Gameplay Depth*
|Shallow, serves curriculum
|Deep, engaging on its own

|*Respect for Player*
|Player is student
|Player is participant

|*Replayability*
|Low (content consumed)
|High (gameplay compelling)
|===

=== Design Principles

[cols="1,3",options="header"]
|===
|Principle |Application

|*Fun First*
|If it's not fun, it fails. No exceptions.

|*Learning Through Play*
|Mechanics naturally teach concepts

|*Respect Intelligence*
|Don't dumb down or patronize

|*Meaningful Choices*
|Player decisions matter

|*Natural Discovery*
|Learning emerges from exploration

|*Kingdom Alignment*
|Content consistent with Kingdom values
|===

'''

|Games must be genuinely enjoyable to play

|*Polish*
|Attention to detail in execution

|*Accessibility*
|Playable by intended audience

|*Stability*
|Games work reliably

|*Performance*

|===

[cols="1,3",options="header"]
|===

[cols="1,3",options="header"]
