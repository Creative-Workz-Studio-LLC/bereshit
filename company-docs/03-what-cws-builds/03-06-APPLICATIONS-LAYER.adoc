== Document Purpose

This document provides detailed coverage of the *Applications Layer (L5)* of the Bereshit stack—the end-user applications that deliver actual value to users. This layer includes the Cornerstone game engine, development tools, and publishing infrastructure.

[NOTE]
====
*The Top of the Stack:* L5 is where all the lower layers become useful to end users. Everything from L0-L4 exists to enable applications that serve real human needs.
====

== Cornerstone Engine

=== Overview

Cornerstone is CWS's game engine—a foundation for building games that are both entertaining and educational.

[sidebar]
****
*The Name:* "Cornerstone" references Jesus Christ as the cornerstone (Ephesians 2:20). Just as Christ is the foundation of the church, Cornerstone is the foundation for Kingdom games.
****

=== Engine Architecture

[source]
----

== Integration with Lower Layers

=== How L5 Uses Lower Layers

[cols="1,2",options="header"]
|===
|Layer |How L5 Uses It

|*L4 (FaithNet)*
|Network communication, distributed features

|*L3 (CPI-SI)*
|AI assistance, intelligent features

|*L2 (Platform)*
|OS services, filesystem access

|*L1 (OmniCode)*
|Scripting, extensibility

|*L0 (libtrit)*
|Core types, ternary operations
|===

=== Direct Layer Access

L5 applications can access layers directly when needed:

* Performance-critical code may use L0 directly
* System utilities may access L2 directly
* Network applications use L4 directly
