== What Core Values Are

=== Definition

[IMPORTANT]
====
*Core values* are the fundamental beliefs and principles that guide all behavior, decisions, and relationships within an organization. They define what is non-negotiable — what CWS will never compromise regardless of circumstances.
====

=== Values vs. Preferences

[cols="1,2,2",options="header"]
|===
|Aspect |Values |Preferences

|*Nature*
|Non-negotiable
|Flexible

|*When Challenged*
|Maintained regardless
|Can change based on situation

|*Decision Role*
|Determines acceptable options
|Influences among acceptable options

|*Compromise*
|Never
|Appropriate when warranted

|*Source*
|Deep conviction
|Practical consideration

|===

=== Why Values Matter

[cols="1,3",options="header"]
|===
|Function |How Values Serve

|*Decision Filter*
|Values eliminate misaligned options before detailed analysis

|*Alignment Test*
|Values verify fit between CWS and potential partners

|*Culture Definition*
|Values shape organizational culture and behavior

|*Drift Prevention*
|Values anchor against mission drift

|*Consistency*
|Values ensure predictable, reliable behavior

|===

'''

=== Values Conflict Resolution

When values seem to conflict:

[cols="1,3",options="header"]
|===
|Step |Action

|*1. Clarify*
|Ensure both values are correctly understood

|*2. Examine*
|Determine if conflict is real or apparent

|*3. Prioritize*
|If real conflict, higher values take precedence

|*4. Seek Wisdom*
|Counsel from Board/leadership for edge cases

|*5. Document*
|Record decision and reasoning for future reference

|===

=== Value Priority
