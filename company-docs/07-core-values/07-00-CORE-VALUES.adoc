This chapter establishes the *eight non-negotiable core values* that guide every {company-short} decision, relationship, and action. These values define who we are and how we operate.

****

== icon:book[] What Core Values Are

=== icon:quote-left[] Definition

[IMPORTANT]
.icon:exclamation-circle[] Foundational Definition
====
*Core values* are the fundamental beliefs and principles that guide all behavior, decisions, and relationships within an organization. They define what is non-negotiable — what {company-short} will never compromise regardless of circumstances.
====

=== icon:columns[] Values vs. Preferences

[cols="^1,2,3,3",options="header",frame=all,grid=all]
|===
|icon:tag[] |Aspect |Values |Preferences

|icon:gem[role=gold]
|*Nature*
|Non-negotiable — cannot be compromised
|Flexible — can change with circumstances

|icon:shield-alt[role=blue]
|*When Challenged*
|Maintained regardless of pressure
|Can change based on situation

|icon:compass[role=green]
|*Decision Role*
|Determines acceptable options — gatekeeper
|Influences among acceptable options — advisor

|icon:ban[role=red]
|*Compromise*
|Never — not for any reason
|Appropriate when warranted

|icon:heart[role=purple]
|*Source*
|Deep conviction and Scripture
|Practical consideration and experience

|===

=== icon:question-circle[] Why Values Matter

[cols="^1,2,4",options="header",frame=all,grid=all]
|===
|icon:tag[] |Function |How Values Serve

|icon:filter[role=blue]
|*Decision Filter*
|Values eliminate misaligned options before detailed analysis — saves time and prevents compromise

|icon:check-circle[role=green]
|*Alignment Test*
|Values verify fit between {company-short} and potential partners — right relationships

|icon:users[role=purple]
|*Culture Definition*
|Values shape organizational culture and behavior — who we are

|icon:anchor[role=orange]
|*Drift Prevention*

=== icon:balance-scale[] Values Conflict Resolution

When values seem to conflict:

[cols="^1,2,4",options="header",frame=all,grid=all]
|===
|icon:tag[] |Step |Action

|icon:search[role=blue]
|*1. Clarify*
|Ensure both values are correctly understood — is this really what the value says?

|icon:eye[role=green]
|*2. Examine*
|Determine if conflict is real or apparent — many "conflicts" dissolve with clarity

|icon:sort-amount-up[role=purple]
|*3. Prioritize*
|If real conflict, higher values take precedence — some values are foundational

|icon:users[role=orange]
|*4. Seek Wisdom*
|Counsel from Board/leadership for edge cases — don't decide alone on hard cases

|icon:file-alt[role=gold]
|*5. Document*
|Record decision and reasoning for future reference — learn from edge cases

|===
