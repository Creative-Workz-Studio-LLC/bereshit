== Document Purpose

This document establishes *Trade and Mutual Support* as CWS's sixth core value — the commitment to decentralized economics, mutual aid, and building economic relationships that function through community rather than through centralized systems.

[.lead]
*"Decentralized economics."*

[quote, Acts 2:44-45 (KJV)]
____
And all that believed were together, and had all things common; And sold their possessions and goods, and parted them to all men, as every man had need.

=== Trade as Ancient Pattern

[IMPORTANT]
====
*Trade predates currency.* Before centralized monetary systems, communities traded directly — goods for goods, services for services. CWS values this pattern as foundation for economic resilience.

== Anti-Patterns

=== Isolation

[sidebar]
****
*What It Is:*

Operating as independent entity without community connection — self-sufficient in way that precludes mutual support.

*Why It Violates Mutual Support:*

Isolation prevents both giving and receiving support. It rejects the Body model. It misses the strength of community.

*Warning Signs:*

* "We don't need anyone"
* No network participation
* Relationships purely transactional
* No support given or received
* Independence valued over interdependence
****

=== Extraction

[sidebar]
****
*What It Is:*

Taking from community more than giving — using network for benefit without reciprocating.

*Why It Violates Mutual Support:*

Mutual support requires mutuality. Taking without giving breaks community. It parasitizes rather than participates.

*Warning Signs:*

* Receiving help but not giving
* Taking referrals but not making them
* Using network resources without contributing
* Relationships only when beneficial to CWS
* "What's in it for us?"
****

=== Conditional Support

[sidebar]
****
*What It Is:*

Supporting others only when convenient, beneficial, or reciprocated — withdrawing support when difficult.

*Why It Violates Mutual Support:*

True mutual support continues through difficulty. Conditional support isn't really support — it's transaction.

*Warning Signs:*

* Support withdrawn when inconvenient
* Help only for "valuable" partners
* Abandoning struggling members
* Expectations of immediate reciprocity
* Calculating ROI on every support act
****

== Tensions and Balance

=== Mutual Support vs. Sustainability

[cols="1,3",options="header"]
|===
|Tension |Resolution

|*Give everything away?*
|No — unsustainable giving eventually stops

|*Help everyone equally?*
|No — some relationships are closer than others

|*Ignore business realities?*
|No — sustainable CWS serves longer

|*Trade when cash works better?*
|Not always — use appropriate exchange method

|===

=== The Balance

Mutual support operates within sustainability constraints. CWS gives generously while maintaining capacity to continue giving. Trade is preferred when appropriate but not forced when cash serves better.
