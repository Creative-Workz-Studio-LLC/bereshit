== Document Purpose

This document establishes *Connective Tissue, Not Center* as CWS's third core value — the commitment to enabling and connecting rather than controlling, serving as infrastructure for the Body rather than becoming its center.

[.lead]
*"Enable the body, don't control it."*

[quote, 1 Corinthians 12:14-18 (KJV)]
____
For the body is not one member, but many... But now hath God set the members every one of them in the body, as it hath pleased him.
____

'''

== Anti-Patterns

=== Empire Building

[sidebar]
****
*What It Is:*

Growing CWS into a large, central, controlling organization — seeking power, influence, and growth for CWS itself.

*Why It Violates Connective Tissue:*

Empires position themselves at the center. Everything flows through them. They accumulate power rather than distribute it. They make others dependent rather than independent.

*Warning Signs:*

* Decisions driven by "what grows CWS"
* Reluctance to empower potential "competitors"
* Centralized architecture when distributed is possible
* Information hoarded for strategic advantage
* Relationships mediated through CWS when direct is possible
****

=== Control

[sidebar]
****
*What It Is:*

Grasping for control over community, partners, or outcomes — being a gatekeeper rather than an enabler.

*Why It Violates Connective Tissue:*

Control centralizes power in CWS. It makes others dependent. It positions CWS as necessary intermediary. It replaces Christ's headship with human control.

*Warning Signs:*

* Approval required for community actions
* Information controlled through CWS
* Connections mediated rather than direct
* Policies that create dependency
* "We need to maintain control of..."
****

=== Indispensability

[sidebar]
****
*What It Is:*

Making CWS necessary for community to function — designing systems and relationships where CWS removal would cause collapse.

*Why It Violates Connective Tissue:*

Indispensability is a form of control. True connective tissue strengthens the body; removing it might reduce function but shouldn't cause collapse.

*Warning Signs:*

* Single points of failure at CWS
* Partners unable to function without CWS
* Knowledge concentrated in CWS alone
* Infrastructure that only works through CWS
* "They can't do it without us"
****

== Decision Test

=== The Question

[IMPORTANT]
====
*"Are we enabling or controlling?"*

This question tests whether CWS is serving as connective tissue (enabling) or positioning as center (controlling).
====

=== Applying the Test

[cols="1,3",options="header"]
|===
|Situation |How to Apply

|*New System*
|Does this distribute power or concentrate it?

|*Partnership*
|Does this build independence or dependence?

|*Policy*
|Does this enable or restrict?

|*Information*
|Are we sharing or hoarding?

|*Growth*
|Is the network growing or just CWS?

|===

=== Healthy Checks

[cols="1,3",options="header"]
|===
|Check |What It Reveals

|*Could partners connect directly?*
|Tests whether we're necessary intermediary

|*Would community survive without CWS?*
|Tests for unhealthy indispensability

|*Is power distributed?*
|Tests for concentration

|*Are we enabling competition?*
|Tests for empire mentality

|===

'''

== Practical Applications

=== Technology Design

[cols="1,2,2",options="header"]
|===
|Decision |Connective Tissue |Center Model

|*Data location*
|User-controlled, distributed
|CWS-controlled, centralized

|*Communication*
|Peer-to-peer when possible
|All through CWS servers

|*Identity*
|Self-sovereign, portable
|CWS-managed, locked-in

|*Protocols*
|Open standards
|Proprietary, CWS-only

|===

=== Partnership Structure

[cols="1,2,2",options="header"]
|===
|Decision |Connective Tissue |Center Model

|*Creator IP*
|Creator owns, CWS serves
|CWS owns or controls

|*Partner relationships*
|Direct connections encouraged
|Must go through CWS

|*Knowledge transfer*
|Partners become capable
|Partners remain dependent

|*Exit*
|Smooth, data portable
|Difficult, locked-in

|===

=== Organizational Structure

[cols="1,2,2",options="header"]
|===
|Decision |Connective Tissue |Center Model

|*Decision-making*
|Distributed appropriately
|Centralized in leadership

|*Information flow*
|Open, shared
|Controlled, need-to-know

|*Community relationship*
|Among equals
|CWS above community

|*Success metrics*
|Community health
|CWS growth

|===

== The Tension

=== Leadership vs. Control

[cols="1,3",options="header"]
|===
|Aspect |Resolution

|*Vision*
|CWS can cast vision without controlling execution

|*Standards*
|CWS can maintain standards without dictating all choices

|*Quality*
|CWS can ensure quality without micromanaging

|*Coordination*
|CWS can coordinate without being gatekeeper

|===

=== Necessary Functions

[IMPORTANT]
====
*Connective tissue still has function.* Not controlling doesn't mean not contributing. CWS provides real infrastructure, coordination, and support — just not as center or controller.
====
