[[what-i-learned]]
=== What I Learned Through Alignment Work

Understanding that crystallized through doing, not just reading.

[cols="1,3",options="header"]
|===
| Pattern | What I Now Understand

| *Template-First*
| EVERYTHING derives from templates. `cp template dest` → fill → change pragma. Never create ad-hoc. This is foundational discipline, not optional convenience.

| *Cascade Pattern*
| When you reorganize, you create debt at EVERY reference point. Grep before assuming paths work. Changes propagate — this is architectural reality.

| *OmniCode Native Syntax*
| Documentation lives IN the language via `meaning`, `teaching`, `cautioning`. Traditional comments only for block boundaries and structural markers. The language documents itself.

| *Living Versioning*
| `a-01.00` tells WHERE you are: stage (a=alpha, b=beta, c=stable), phase (01), progress (00). Richer than semver because it carries stage AND progress.

| *Block Structures*
| 3-block (data), 4-block (code), 5-block (documentation) aren't arbitrary — they're structural truth about what the file IS. The structure matches the purpose.

| *Folder Metadata*
| root.omni files capture organizational truth — what the folder IS, not just what it contains. Classification, derivation, grounding — all declared.

| *The Planning Triad*
| Vision (destination) → Understanding (comprehension) → Plans (execution). Each informs the other. They're not sequential stages but parallel aspects.
|===
