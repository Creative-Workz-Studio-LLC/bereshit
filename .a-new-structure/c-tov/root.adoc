= c-tov

Tov (טוֹב) — good, complete, finished. The exit gate where implementations
become deliverables. Named for Genesis 1:31: God saw everything He had made
and declared it "very good."

== Structure

----
c-tov/
├── cws-struct/        ← DAR engine — schema-driven structural alignment tool
├── cwe-creator-tools/ ← 8 standalone Deno format scripts
├── definitions/       ← base and regional definitions
├── demo/              ← phase validation demos
├── licenses/          ← three-license structure
├── patterns/          ← discovered, instance, and user patterns
├── pricing/           ← Kingdom Tech Stack pricing
├── projects/          ← project template specs (high/mid/low level)
├── scripts/           ← setup and development environment scripts
├── session/           ← session management schemas
└── temporal/          ← time tracking (appointed, celestial, chronological)
----
