// # T.3 Staging Process [PROCESS]
//
[[staging-process]]
== Staging Process

=== The tov/ Pattern

Most content follows this flow:

[source]
----
void/ (planning) → word/ (substance) → tov/ (completion)
----

Direct void/ → tov/ graduation is rare and reserved for:

* Finished vision artifacts (manifestos, mission statements)
* Complete demo packages ready to showcase
* Ready-to-ship products

=== When Content Graduates to tov/

Content reaches tov/ when it embodies Genesis 1:31 — "and behold, it was very good":

. *Complete* — No more work needed
. *Polished* — Ready for external presentation
. *Finished* — Represents final form, not work in progress

=== Post-Move Checklist

. [ ] Verify content is truly "finished" not "in progress"
. [ ] Move to appropriate tov/ subdirectory
. [ ] Update this manifest (mark as staged)
. [ ] Commit with message: "BATON: Stage [item] from void/ to tov/"
