[[stack-flow-detail]]
=== stack-flow.adoc — L0-L5 Stack Architecture

The canonical layer stack definition:

* **L0 (Universal)**: Foundational primitives — libtrit, balanced ternary, Genesis 1:1 anchor
* **L1 (Runtime)**: Core execution — OmniCode VM, memory management, type system
* **L2 (Platform)**: OS integration — MillenniumOS, filesystem abstraction, permissions
* **L3 (Services)**: System services — networking, storage, health monitoring
* **L4 (Frameworks)**: Development tools — OmniCode IDE, CPI-SI runtime, templates
* **L5 (Applications)**: User-facing — games, utilities, Kingdom Technology products

[[dependencies-detail]]
=== dependencies.adoc — Self-Hosting Roadmap

Dependency analysis and reduction strategy:

* **Current state**: Go and C external dependencies cataloged
* **Self-hosting tiers**: Tier 1 (achievable now) → Tier 2 (medium) → Tier 3 (full)
* **Kingdom independence**: Build on proper foundations, not borrowed infrastructure
