....

=== Three-Layer Config Architecture

[cols="1,4,3",options="header"]
|===
| Layer | Purpose | Location

| *0: Anchor*
| TOML Specs — The immutable truth. Defines WHAT things ARE. Never changes at runtime.
| `word/core/`, `schema/config/`

| *1: Schema*
| Go Loaders — The processing layer. INTERPRETS the TOML specs into usable structures.
| `pkg/foundation/schema/loader.go`, `pkg/core/health/loader.go`

| *2: Runtime*
| JSON Files — The mutable state. Contains KEYS that reference back to Layer 0.
| `config/statemachine/runtime/state.jsonc`, `path.jsonc`
|===

[NOTE]
====
*State files contain KEYS, not values:*
[source,json]
----
{
  "anchor_key": "present_present",  // Key into anchors.toml
  "command_key": "halt",            // Key into statemachine.toml
  "hebrew_state": 3                 // Index (0-6 = 7 Days)
}
----
====

// # T.4 Runtime Data Flow [RUNTIME-FLOW]

[[runtime-flow]]
== Runtime Data Flow

[.lead]
Session lifecycle, state machine navigation, and health scoring.

=== Session Lifecycle

....
    ┌─────────────────────────────────────────────────────────────────────────┐
    │                        SUBSTRATE (Claude Code)                           │
    │   User starts session ──► Claude Code fires hook ──► JSON payload        │
    └──────────────────────────────┬──────────────────────────────────────────┘
                                   │
    ╔═════════════════════════════════════════════════════════════════════════╗
    ║                          SESSION START                                   ║
    ║   1. Parse input (source = startup | resume | clear | compact)           ║
    ║   2. Initialize or Load state                                            ║
    ║   3. Initial: position=present_present, health=0, hebrew_state=0         ║
    ║   4. Save state to disk (state.jsonc)                                    ║
    ║   5. Record in database (bridge.StartSession)                            ║
    ║   6. Generate context for substrate                                      ║
    ╚═════════════════════════════════════════════════════════════════════════╝
                                   │
    ╔═════════════════════════════════════════════════════════════════════════╗
    ║                          TOOL EXECUTION                                  ║
    ║   PRE-TOOL-USE: Capture baseline, determine intended_key from tool       ║
    ║   POST-TOOL-USE: Compare intention vs outcome, calculate health delta    ║
    ╚═════════════════════════════════════════════════════════════════════════╝
                                   │
    ╔═════════════════════════════════════════════════════════════════════════╗
    ║                          SESSION END                                     ║
    ║   1. Mark session inactive                                               ║
    ║   2. Finalize in database                                                ║
    ║   3. Snapshot to history.jsonc (cross-session learning)                  ║
    ╚═════════════════════════════════════════════════════════════════════════╝
....

=== The 27-Position State Machine

....
                              THE 3×3×3 CUBE
                         ═══════════════════════

                    Future Layer (z=+1)
                    ┌─────┬─────┬─────┐
                    │ F-P │ F-Pr│ F-F │
                    ├─────┼─────┼─────┤
                    │ Pr-P│Pr-Pr│ Pr-F│   ← Present Layer (z=0)
