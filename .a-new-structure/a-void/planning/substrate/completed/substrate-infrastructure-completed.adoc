=== PLAN-005: Hooks Schema Alignment

[quote]
____
_"Let all things be done decently and in order."_ — 1 Corinthians 14:40
____

*Completed:* 2025-12-23

*The Problem:* Hooks were building context but Claude never SAW it because output schemas didn't match what Claude Code expects.

*The Fix:* `hookSpecificOutput` wrapper with correct field names.

*Schema Changes:*

[cols="2,3,3",options="header"]
|===
| Hook | Before | After

| SessionStart
| `{"additionalContext": "..."}`
| `{"hookSpecificOutput": {"hookEventName": "SessionStart", "additionalContext": "..."}}`

| UserPromptSubmit
| `{"injected_context": "..."}`
| `{"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": "..."}}`

| PreToolUse
| `{"decision": "allow"}`
| `{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "allow"}}`

| PostToolUse
| `{"additionalContext": "..."}`
| `{"hookSpecificOutput": {"hookEventName": "PostToolUse", "additionalContext": "..."}}`
|===

*The Key Insight:* We weren't building a state machine. We were ACTIVATING one. The architecture existed — it just couldn't deliver its output.
