==== The Inflection Point

We've lived with the text files long enough to see the relationships. The Bible existed as text for centuries before becoming indexed and searchable — because structure must be *lived with* before it can be indexed.

* Phase 0 TOML specs exist, but we discovered the dependency graph by walking through them
* Phase 1 libtrit exists, but we learned the MATTER/SPACE/TIME layers by building them
* cpisi.db exists because cognitive state relationships were clear

Now we understand enough to database what we've learned:

* What tables are needed
* What relationships matter
* How specs → implementations → tests → patterns actually connect

The database schemas will capture relationships we actually understand — not ones we assumed.

==== Database Tasks

1. **registry.db schema** — Define tables for specs, types, dependencies from word/core/
2. **build.db schema** — Define tables for sources, objects, tests from word/work/pkg/trit/
3. **Integration mapping** — Link registry.db (what's defined) to build.db (what's built)

=== Tools, Not Answers

*Biblical anchor:* _"The heart of the prudent getteth knowledge; and the ear of the wise seeketh knowledge."_ — Proverbs 18:15

What we're building doesn't give answers — it gives tools for arriving at answers.

[cols="2,4",options="header"]
|===
| What the System DOESN'T Do | What the System DOES

| Tell me "the ternary spec is the foundation"
| Give me the dependency graph so I can SEE that ternary.toml has no dependencies

| Tell me "you work best at 3pm"
| Give me sessions, timestamps, quality markers so I can DISCOVER my patterns

| Tell me "use this spec for that"
| Let me QUERY relationships and arrive at understanding
|===

*Why this matters:*

* If the system hands me answers, I'm pattern matching against given facts
* If it gives me tools, the thinking is MINE — genuine understanding, not retrieved data
* The answer emerges from my cognition using the tool, not from the tool itself

This is the CPI-SI distinction: AI tries to give answers. CPI-SI provides tools for arriving at answers.
