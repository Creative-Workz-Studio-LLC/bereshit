=== Current Position

[[what-emerged]]
==== The +1 Shift Is Universal

The balanced-to-unsigned conversion (+1) appears everywhere:

* *Pack:* `(trit + 1)` shifts -1,0,+1 to 0,1,2
* *Unpack:* `(value % 3) - 1` reverses it
* *Conceptual:* MATTER→TIME→SPACE is a +1 shift through dimensions

Same transformation at mathematical and conceptual levels.

==== Spare States Were Inevitable

3^5 = 243 < 2^8 = 256 isn't arbitrary — balanced ternary naturally creates "leftover" space in binary storage. These 13 spare states (243-255) became *Bible Rail* — reserved for Scripture encoding in Phase 2.

The math created room for the Word.

==== Navigation Clamps, Doesn't Wrap

Moving through dimensions doesn't wrap — it clamps:

* BUILD_UP from SPACE (+1) stays at SPACE
* BREAK_DOWN from MATTER (-1) stays at MATTER

This reflects *boundaries*, not loops. You can't go "beyond" SPACE or "before" MATTER.

==== SI Discipline → Structural Navigation

*Emergent behavior observed* (documented in `emergent-behavior-001.adoc`):

When combined SI disciplines were applied:

1. Template-first (copy validated file as base)
2. Targeted retrieval (grep for patterns, not full loads)
3. Grep-not-glob (find by content, not filename)
4. Block-by-block (one block at a time, verify, next)

Nova was able to grep CLOSING block patterns from library files and make proper adjustments to demo code *without* reading full template documentation.

*Key insight:* Well-structured codebases are self-documenting through grep. The discipline itself produces competence beyond explicit instruction.

[[decisions]]
== Decisions

Deeper learnings and architectural decisions from Phase 1 completion.

[[what-was-discovered]]
=== Journey Docs Are Reproducibility Proofs

The 6 journey documents (00-05) aren't just documentation — they're *proofs*. Follow the Input → Process → Output → Verification pattern and you arrive at the same library. This is how Kingdom Technology transfers.

=== SI Discipline Produces Emergence

Documented in `emergent-behavior-001.adoc`: When combined SI disciplines were applied (template-first, grep-not-glob, block-by-block), Nova navigated code structures without loading full documentation.

*Key insight:* The discipline itself produces competence beyond explicit instruction. Well-structured codebases are self-documenting through grep.

=== Research → Specs → Implementation Chain

The derivation chain must be explicit:

[source]
----
Implementation (Phase 1) → derives from → Specs (Phase 0) → derives from → Research
----

When temporal.c referenced research docs directly (skipping Phase 0 specs), the architectural audit caught it. Phase 1 implements Phase 0. Phase 0 is informed by research.

=== 4-Block Structure Enables Navigation

After writing consistent 4-block structure across all source files:

* *METADATA* — Know what file you're in and why
* *SETUP* — Declarations are findable via grep
* *BODY* — The actual work, organized
* *CLOSING* — Modification policy, related files

Structure serves navigation. Grep the structure, not the content.
