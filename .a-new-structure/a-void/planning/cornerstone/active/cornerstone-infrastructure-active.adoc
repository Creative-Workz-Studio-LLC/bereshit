**Goal:** Add CWS splash screen before launcher, fix scene stack flow.

**Files:**
- `engine/include/framework/service/startup_service.h` (NEW)
- `engine/src/framework/service/startup_service.c` (NEW)
- `engine/include/framework/scene.h` (add SCENE_STARTUP enum)
- `engine/src/framework/scene.c` (register callbacks, wire service)
- `cornerstone.c` (create/register service, change startup flow)
- `engine/src/framework/service/title_service.c` (fix Game Selector spacing)

**Implementation Tasks:**

| # | Task | Status

**StartupService State:**
```c
typedef struct StartupServiceState {
    ServiceOrchestrator* orchestrator;
    StartupPhase phase;      // LOGO → FADE
    float timer;
    bool active;
    BlockFont font;
    Texture logo;
} StartupServiceState;

#define STARTUP_SPLASH_DURATION 2.5f
```

**Expected Flow After Implementation:**
----
SCENE_STARTUP (splash: logo + "CreativeWorkzStudio LLC", 2.5s)
  ↓ (auto or key press)
SCENE_LAUNCHER (Engine / Editor / IDE)
  ↓ (Engine selected)
SCENE_TITLE (Game Selector)
  ↓ (game/demo selected)
SCENE_LOADING → SCENE_GAME_MENU → Gameplay
----

=== Phase 7: Scene Logic Extraction

**Problem:** scene.c (~3500 lines) contains ALL scene logic inline.

**Target reduction:**

[cols="2,^1,2",options="header"]
|===
| Component | Lines | Action

| Title scene
| ~330
| KEEP

| Dialogue scene
| ~1100
| REMOVE (use DialogueService)

| Combat scene
| ~650
| REMOVE (use CombatService)

| Demo complete
| ~140
| KEEP

| JSONC helpers
| ~220
| REMOVE (duplicate)
|===

**Target scene.c:** ~500 lines (orchestrator only)

=== Phase 8: Event-Driven Flow

**Current (problematic):**
----
scene.c → load_current_line() → scene_transition_to(SCENE_COMBAT)
----

**Target (event-driven):**
----
DialogueService.advance_line()
  → emit DIALOGUE_EVENT_COMPLETE {has_encounter, encounter_name}
  → CombatService receives (subscribed)
  → orchestrator_push(combat_service)
----
