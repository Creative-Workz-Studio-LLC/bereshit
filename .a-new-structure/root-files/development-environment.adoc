=== CUDA Configuration

[NOTE]
====
Added 2026-02-03. CUDA is optional — only required for GPU compute
development. Skip this section if your work doesn't involve GPU acceleration.
====

[source,bash]
----
# Environment variables (in ~/.bashrc)
export CUDA_HOME=/usr
export PATH=$PATH:/usr/lib/nvidia-cuda-toolkit/bin
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/lib/x86_64-linux-gnu
export NVCC_PREPEND_FLAGS='-ccbin /usr/bin/g++-13'
----

[horizontal]

== "Anyone Can Use It" Philosophy

[.lead]
Development environments are often tied to one person's machine, full of
undocumented dependencies, impossible to reproduce on another system.
The solution: *layered reproducibility*.

[source]
----
+--------------------------------------------------+
| Layer 4: IDE/Editor Config                       |
| (VS Code settings, keybindings - synced)         |
+--------------------------------------------------+
| Layer 3: Project-Specific (CLAUDE.md, Makefile)  |
| (Checked into repo, travels with code)           |
+--------------------------------------------------+
| Layer 2: Containerized Environment               |
| (Dockerfile, devcontainer.json)                  |
+--------------------------------------------------+
| Layer 1: System Dependencies                     |
| (Documented, scripted installation)              |
+--------------------------------------------------+
----


'''


== Recommendations for {project-name} Projects

=== 1. System Dependencies (Layer 1)

Setup script: `.a-new-structure/c-tov/scripts/setup-dev-environment.sh`

[source,bash]
----
# Full install — installs all required system dependencies
./scripts/setup-dev-environment.sh

# Quick verify — check what's installed without installing
./scripts/setup-dev-environment.sh --verify-only

# Structured verify — tool presence + minimum versions
cws-struct verify env
cws-struct verify env --verbose   # include optional tools
----

The setup script uses `pkexec` for elevated permissions on desktop
environments (GUI password dialog) with fallback to `sudo` for headless.


=== 2. Containerization (Layer 2)

[.lead]
For true "anyone can use it" portability.

*Option A: Docker Development Container*

[source,dockerfile]
----
# Dockerfile.dev
FROM ubuntu:25.10

# Install base dependencies
RUN apt-get update && apt-get install -y \
    build-essential \
    golang-go \
    rustc \
    asciidoctor \
    git

# For CUDA support, use nvidia/cuda base image instead
# FROM nvidia/cuda:12.4-devel-ubuntu25.10

WORKDIR /workspace
----

*Option B: VS Code Dev Containers*

[source,jsonc]
----
// .devcontainer/devcontainer.json
{
  "name": "Bereshit Development",
  "build": {
    "dockerfile": "Dockerfile"
  },
  "features": {
    "ghcr.io/devcontainers/features/go:1": {},
    "ghcr.io/devcontainers/features/rust:1": {}
  },
  "customizations": {
    "vscode": {
      "extensions": [
        "golang.go",
        "rust-lang.rust-analyzer",
        "asciidoctor.asciidoctor-vscode"
      ]
    }
  }
}
----
