= L2 Platform

== Purpose

MillenniumOS — the operating system where Kingdom Technology runs natively.
Ternary-native kernel, zone-aware filesystem integration, balanced ternary
hardware abstraction. The firmament between hardware and applications.

== Current Location (pre-migration)

== Target Structure

----
L2-platform/
├── millenniumos/   ← full OS (15K+ files, separate build system)
├── filesystem/     ← native ternary filesystem
├── fuse/           ← FUSE bridge layer
└── drivers/        ← hardware abstraction
----

== Build

 make l2

Delegates to `millenniumos/`. Separate build system — do NOT touch internals
without understanding the full OS architecture.
