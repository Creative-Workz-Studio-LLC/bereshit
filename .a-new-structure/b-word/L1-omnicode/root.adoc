= L1 OmniCode

== Purpose

The OmniCode programming language — sentence-like syntax where the Bible
serves as the codex. Frontend parsing, intermediate representation, semantic
analysis, code generation. All built on L0's balanced ternary foundation.

== Target Structure

----
L1-omnicode/

├── semantic/       ← type checking, analysis
├── runtime/        ← runtime support
├── stdlib/         ← standard library
