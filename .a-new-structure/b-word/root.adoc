= b-word

The Word — implementations, definitions, and everything that exists in the
Bereshit project. Named for the Hebrew concept that God spoke creation into
being. Code is the word that speaks systems into existence.

== Layer Stack (L0-L5)

[cols="1,2,2,1"]
|===
| Layer | Name | Purpose | Language

| L0 | Universal | libtrit, bereshit-fs, math | C
| L1 | OmniCode | Language, compiler, VM | C
| L2 | Platform | MillenniumOS | C
| L3 | CPI-SI | Intelligence model | Go
| L4 | FaithNet | Network services | Go/Rust
| L5 | Applications | Cornerstone, user apps | C#
|===

== Support Directories

[cols="2,3"]
|===
| Directory | Purpose

| substrates/ | Substrate-specific code (Claude Code, MillenniumOS)
| interface/ | User interaction (CLI, TUI, GUI, game)
| definitions/ | Vocabulary and specifications
| data/ | Static content (scripture, journals)
| seed/ | Templates and generators
| build/ | Cross-language build infrastructure
|===

== Build Streams

 Stream 1 (C):    L0 → L1 → L2
 Stream 2 (Go):   L3 → L4
 Stream 3 (C#):   L5

No upward imports. Higher layers depend on lower, never reverse.
