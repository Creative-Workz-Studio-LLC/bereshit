== Three-Domain Pattern (Fractal)

Every layer is organized by execution mode — a fractal pattern discovered at
L0 and applied to every layer:

[cols="1,2,3"]
|===
| Mode | Characteristic | Role

| *Ladder*
| Strict sequence, baton-passing
| Specifications, compiled foundations, definitions

| *Spiral*
| Iterative growth, self-awareness
| Identity registries, glossaries, self-description

| *Hybrid*
| Ordered execution with spiral recovery
| Runtime packages, parsers, dispatchers
|===

The pattern is ontological, not organizational — these three natures are
inherent to how any self-aware structure works. Genesis 1 parallel: every
day of creation has sequence (ladder), naming (spiral), and making (hybrid).

== Build Streams

 Stream 1 (C):    L0 → L1 → L2
 Stream 2 (Go):   L0 → L1 → L3 → L4
 Stream 3 (Rust): L0 (config, identity, paths, cli, format, output)
 Stream 4 (C#):   L5

No upward imports. Higher layers depend on lower, never reverse.
