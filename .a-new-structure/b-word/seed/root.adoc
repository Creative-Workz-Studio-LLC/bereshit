= Seed

== Purpose

Templates and generators. The starting point for new files. Copy from here,
adapt to purpose — never write structured files from scratch. Seeds yield
consistent, well-structured offspring.

== Current Location (pre-migration)

[cols="2,3"]
|===
| Component | Current Path

| Code templates
| `word/seed/code/`

| Data templates
| `word/seed/data/`

| Documentation templates
| `word/seed/documentation/`
|===

== Target Structure

----
seed/
├── code/           ← 4-block code templates (Go, C, Bash, Python)
├── data/           ← 3-block data templates (TOML, JSONC)
├── documentation/  ← 5-block doc templates (AsciiDoc, Markdown)
└── compiler/       ← OmniCode compiler templates (future)
----
