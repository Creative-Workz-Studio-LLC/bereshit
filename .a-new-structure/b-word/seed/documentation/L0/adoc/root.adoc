[[schema]]
== The 34-Section Schema

All 5 templates share identical structure — 34 addressable sections across 5 blocks:

[cols="1,2,3",options="header"]
|===
| Block | Sections | Purpose

| *METADATA*
| M.1-M.12 (12)
| Identity, state, attribution, location, derivation, classification, intent, grounding, strictness, settings, navigation, content attributes

| *HEADER*
| H.1-H.6 (6)
| Title, epigraph, lead, abstract, status, navigation

| *CONTEXT*
| C.1-C.8 (8)
| Overview, scope/welcome, quick start, contents, prerequisites, terms, usage, return

| *CONTENT*
| T.1-T.4 (4)
| Primary content sections (varies by template type)

| *FOOTER*
| F.1-F.4 (4)
| Biblical foundation, references, see also, closing
|===

*The index window pattern:* Navigate via grep (`grep '// # M.1' template.adoc`) without loading the entire file.
